## 2. 발견·수정 내역 (사용자 결정 반영)

1. **나사머리 0.8 돌출** → 하판 밑면 카운터보어 **Ø2.8×0.9** 추가(머리 0.1 은닉, 잔여 웹 0.6). 연쇄: 머리가 0.9 올라가 나사끝이 기존 포켓(3.0) 천장을 0.2 관통 → **인서트 포켓 3.0→3.6 심화**로 M1×4 나사 그대로 사용(여유 0.4, 물림은 2.3→2.5 풀 물림으로 개선). 정점 측정 일치.
2. **중앙 보스↔인접 하우징 0.33** → `MOUNT_HOLE_OUTSET` 1.5→**2.0**(마운트홀 6개 0.5 외측 이동). 갭 0.83, plate 컷웹 1.03→1.5+, 케이스 외형 불변. (worst-case 하우징 14.0 기준값이며 실물 테이퍼 감안 시 더 여유)
3. **USB 케이블 제거 시 모듈 후방 이탈 위험** → 형상 무변경, **실물 검증 후 결정**(사용자). 아래 체크리스트에 등재.
4. fit coupon: **생략**(사용자) — 1/5 미니빌드·본출력으로 검증.

smoke 가드 추가: M1 물림·포켓 여유·머리 은닉 / boss↔housing 최소 갭 — 이후 치수 변경 시 자동 차단.

## 3. 실물 출력 후 확인 체크리스트

- [ ] plate 실두께 ≥ 1.3 확인 (미달 시 기둥이 보어 바닥에 닿아 베젤 들뜸 — tip 여유 0.2 설계)
- [ ] 중앙 보스(좌 x−2 / 우 x+79.7, y−47.6) ↔ 인접 스위치 하우징 접촉 여부 (설계 갭 0.83)
- [ ] USB-C 케이블 분리 시 ESP32 모듈 이탈 여부 — 이탈하면 립 후단 스냅 범프/클립 설계 추가 (분리 시 모듈을 잡고 뽑을 것)
- [ ] 스위치 컷 14.0 실핏 (헐거우면 13.9 재수렴 — FDM 수축 반대면 확장)
- [ ] plate 6홀 동시 슬라이드 조립성 (Ø5.4 vs 기둥 Ø4.8, 카운터싱크 렌즈인)
- [ ] M1×4 체결 시 머리가 카운터보어에 완전 은닉되는지 / 바닥 수평 안착
- [ ] 납땜 후 row0 아래 와이어·다이오드가 ESP32 본체 위(여유 1.1)로 지나가는지

## 4. 참고 (변경 불요 판단)

- **측면 12.5mm 완전 개방**(둘레 벽 없음, 배선·모듈 노출): split-65 FDM 방식 승계의 의도적 구조. 가릴 필요가 생기면 스커트 별도 설계.
- 키캡 스커트는 미압 시 plate 위 ~2mm(disputed)까지 내려옴 — 베젤(5.0)이 측면을 가리므로 무영향.
