# Cherry MX 표준 확정 치수표

> 멀티소스 조사 + 교차검증 결과. 출처: `docs/reference/cherry-mx-sources.md`. 조사일 2026-06-21.
> 신뢰도: **confirmed**(독립 출처 2+ 일치) / **range**(출처 간 범위) / **disputed**(권위 출처 부족·정의 모호).
> ⚠️ "전체 높이"류는 **측정 기준면**에 따라 값이 달라지므로 항상 기준을 명시한다.

| --------------------------------------- | ------------------------------------------------ | :-------: | -------------------------------- |
| 플레이트 스위치 컷아웃 (정사각)         | **14.0 × 14.0 mm** (공식 13.995, 코너 R 0.3 max) | confirmed | 4개 출처 일치                    |
| 컷아웃 fit 튜닝 범위                    | 13.8 ~ 14.06 mm                                  |   range   | 작을수록 타이트(클립 압력↑)      |
| 플레이트 두께 (= 스냅인 노치 폭)        | **1.5 mm ±0.1**                                  | confirmed | 스위치 턱~retention clip 노치 폭 |
| 플레이트 두께 사용 범위                 | 1.2 ~ 1.6 mm (1.5 표준)                          |   range   | 3mm 아크릴은 스냅 불가           |
| **plate 상면 → PCB 상면**               | **5.0 mm**                                       | confirmed | ai03·Cherry도면·Telcontar 일치   |
| **plate 하면 → PCB 상면 (순수 에어갭)** | **3.5 mm** (= 5.0 − 1.5)                         | confirmed | 기준면만 다를 뿐 같은 표준       |
| PCB 두께                                | 1.6 mm (FR4 표준)                                |   high    | split-65 JLCPCB 일치             |
| 핫스왑 소켓(Kailh) PCB 하부 돌출        | ~1.8 ~ 2.0 mm                                    |    low    | Kailh 1차 데이터시트 미확보      |

> ‼️ **3.7mm 를 plate-to-PCB 로 쓰지 말 것** — 그것은 stem 자체 높이 혼동값. 표준은 **5.0(plate 상면 기준) / 3.5(plate 하면 에어갭 기준)**.

### 마운트 핀 (PCB-mount 5핀 vs plate-mount 3핀)

- **plate-mount = 3핀**: 중앙 가이드 보스 1 + 금속 접점핀 2
- **PCB-mount = 5핀**: 위 3핀 + 플라스틱 고정핀 2 (5핀의 추가 2개를 잘라내면 3핀 변환 가능)
- PCB 홀: 중앙 보스 핀 Ø3.99 → PCB 홀 Ø5.0 / 금속 접점핀 홀 Ø1.50 / 5핀 고정핀 홀 Ø1.70 / 3핀 보조홀 Ø0.99

### 스템 +자(cross) 마운트

- 전체 폭 4.0 × 4.0 mm / 가로(E-W) 암 1.25–1.30 / 세로(N-S) 암 1.05–1.10 (가로>세로 비대칭이 MX 특징)
- 키캡 내부 슬롯(암컷): 십자 폭 4.1 mm, 암 1.17 mm → 스템과 억지끼움

> **외벽 높이 주의**: Cherry 등 어떤 제조사도 단일 "skirt height" 수치를 발표하지 않는다(전부 total height만). 정밀값이 꼭 필요하면 STEP/STL 원본(GitHub ConstantinoSchillebeeckx, Printables)을 CAD로 실측해야 한다. 케이스 베젤(외벽) 설계용으로는 "키캡 하단 ~18mm + 와블 여유, 스커트가 플레이트 위 ~2mm까지 내려옴" 정도로 잡는다.

## 4. 전체 조립 스택업 (PCB 상면 = 0, 위로 누적)

| 구간                           | 높이        | 비고                         |
| ------------------------------ | ----------- | ---------------------------- |
| PCB 상면 → plate 하면 (에어갭) | 3.5 mm      | 이 구간에 스위치 핀          |
| → plate 상면                   | 5.0 mm      | plate 두께 1.5 포함          |
| → top housing 상단             | ~13.0 mm    | 유도값(±0.5)                 |
| → 미압 스템 상단               | 16.6 mm     | 확정                         |
| → 키캡 윗면 (미압)             | ~18 ~ 22 mm | Cherry캡 ~18–19 / OEM ~21–22 |
| PCB 하면 ↓ 핀 돌출 (솔더)      | −3.30 mm    | 핫스왑이면 소켓 ~2mm         |
| bottom-out 시 하강             | −4.0 mm     | actuation은 −2.0 지점        |

## 5. split-65 적용 시사점

- **컷아웃**: KLE-NG 원본 생성값은 13.75mm였으나, **현재 설계는 13.95mm 채택**(아크릴 레이저컷 snug 핏 — geekhack 59837, Cherry 13.9954±0.0508). `65/config/dimensions.js SWITCH_CUTOUT=13.95`. ⚠️ 레이저 kerf ~0.2mm 보정 필요(실측 13.95 목표). 참고: 13.75는 표준 14.0보다 0.25mm 작아 금속엔 타이트했고, 13.95는 Cherry 규격 공차 안의 적정 snug.
- **플레이트 두께 1.5mm / 피치 19.05 / PCB 1.6mm**: 모두 표준과 **일치(confirmed)**.
- **plate↔PCB 에어갭 = 3.5mm**(보강판 **하면** 기준): 표준 5.0 − plate 1.5 = 3.5. ⚠️ plate 상면 기준 5.0을 그대로 쓰면 두께 1.5 중복 합산되므로 주의. **현재 설계(v3, `case-construction.md` §13)** 는 이 3.5mm를 **좌·우 아크릴 벽**이 유지한다(필드의 plate↔PCB는 스위치가 span). 과거 H빔 외벽 단/둘레벽/기둥 스페이서 역산식은 §1~12 이력 참고용.

## 6. 케이스 베젤(외벽 프레임) 설계 가이드 — geekhack 104376 (커뮤니티 경험)

> 출처: geekhack 104376 (mike-y). **공식 규격 아님**, 하이프로파일 케이스 실무값. 우리 설계 B(스페이서 샌드위치)의 상판 프레임 높이/개구부에 직접 적용.

| 항목                                          | 값                  | 의미                                                                |
| --------------------------------------------- | ------------------- | ------------------------------------------------------------------- |
| **plate 상면 → 케이스 벽 최상단 (베젤 높이)** | **7.5 mm** (최소 7) | 7mm 미만이면 **키캡 하단에 틈이 보임**. 7.5–7.7이 하이프로파일 표준 |
| 키캡 ↔ 케이스 벽 측면 클리어런스              | **3 mm / side**     | 외곽 스위치열 센터라인에서 10mm 안쪽 = 케이스 내벽 위치             |
| plate 하면 → 케이스 클리어런스                | 3 mm (2 위험)       | PCB 하면 부품이 케이스에 닿지 않게                                  |

### 설계 B(우리 안)에 적용 — 베젤 높이 재검토

- 베젤 높이 = plate 상면 → 상판 프레임 **윗면** = (상판↔보강판 스페이서) + (프레임 두께).
- 키캡은 plate 위로 **약 13~17mm** 솟음(키캡 top), 키캡 하단은 plate 위 **~~3.6~~5.6mm**.
    - 벽 7.5mm → 키캡 **하단 틈만 가림**(키캡 거의 다 노출). **표준/저프로파일감.**
    - 벽 10~12mm → 키캡 **측면 절반 감쌈**(중간 well).
    - 벽 ~13mm(스페이서 10 + 프레임 3) → 키캡 **대부분 감쌈**(깊은 well, 키캡 살짝만 노출). ← 이전 결정값. **의도 확인 필요**.
- 측면 클리어런스 3mm/side → 상판 프레임 **안쪽 개구부 = 키 클러스터 외곽 + 3mm씩**.
