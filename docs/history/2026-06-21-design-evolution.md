# 2026-06-21 — 설계 진화 + 정정 이력

> 케이스 설계가 여러 번 바뀐 과정과 이유. 새 세션이 "왜 현재 형태인지" 알고, 지난 실수를 반복하지 않도록.
> 현재 상태는 `docs/PROCESS.md`. 초기 뷰어 구현은 `2026-06-21-case-viewer-implementation.md`.

## 설계 진화 (시간순)

1. **H빔 일체 CNC** (사용자 첫 개념도): 보강판 + 외벽이 하나의 CNC 부품(H빔 단면), PCB는 그 아래, 하판이 바닥. → `case-construction.md` §1~7.
2. **스페이서 샌드위치(설계 B)**: H빔 외벽을 깎는 대신 평판 레이어(상판 프레임/보강판/하판)를 M3 스탠드오프로 적층. CNC 단순·키트 활용. → §8.
3. **결착 문제 발견**: 보강판↔PCB는 3.5mm(스위치 핀 공간) 고정인데 키트 스탠드오프 최소 6mm → 그 구간 못 채움. 처음엔 "스위치가 유지"로 정리(§9).
4. **핫스왑 전제** (사용자): 핫스왑이면 스위치가 빠져 구조재 못 됨. → plate↔PCB **직접 결착** 필요. 선택지(인서트/관통볼트/스위치홀드) 중 **플레이트 일체형 보스** 채택 → 곧 **둘레 벽**으로 바뀜.
5. **❌ 오해 1**: "벽을 파란색(보강판)에 적용, 노란/검은 불필요, 노출"을 **프레임·하판 제거 + 보강판 일체 벽**으로 잘못 구현. → 사용자가 "노란상판 검은하판 그대로, 보강판 기둥8개를 벽으로"라고 정정. **되돌림**: 프레임·하판·스페이서 복구 + 보강판의 둥근 보스 8개 → **둘레 벽**. (현재)
6. **재질 = 아크릴(PCB 제외)**: 보강판을 레이저컷 2겹 적층(field 1.5 + ring 3.5). export를 **레이어별 DXF**로. 결착은 아크릴이라 **열간 인서트**.
7. **프레임 개구부 = 키 클러스터 실루엣**: 사각 개구부 → 키 셀 union → 키 없는 틈(빠진 4,3·스태거드 가장자리)을 노란색으로 덮음.
8. **❌ 오해 2 (radius)**: 틈 머리(오목 코너)에 **원을 꼭짓점에 union** → scoop처럼 파먹힘. + 모든 키 셀에 roundRadius → 키마다 둥글어짐. 사용자 정정: 키 구멍은 사각, **틈 머리만 매끄러운 radius**. → **접선 fillet**(`filletOutline`, 두 변에 접하는 호)으로 재구현. (expand 모폴로지는 DXF 직렬화에서 깨져 사용 불가.)
9. **미세조정**: 컷아웃 13.95(레퍼런스), 키캡↔외벽 1.25, 상판 스페이서 너트 2.4mm, fillet 1.0.
10. **관통 볼트 클램프 전환 (현재, 2026-06-25)**: 둘레 벽 + 열간 인서트(6~8단계 결과)를 **전면 폐기**. 아크릴 열압입 크랙 위험 + 둘레벽(2겹 적층) 가공·정렬 부담 때문. 보강판은 **평판 1겹**(field 1.5)으로 복귀, 모서리 8곳 M3 긴 볼트가 전층 관통(모든 아크릴 Ø3.2 클리어런스, **끝 너트만 나사산**), 상판 프레임은 **1.5+1.5 2겹**으로 볼트머리 카운터보어(Ø6). plate↔PCB 3.5mm는 **별도 기둥 스페이서**. → `case-construction.md` §12.

## 새 세션이 피해야 할 함정 (lessons)

- **노란 프레임·검은 하판은 유지**한다. 보강판(파란)은 **평판 1겹**(field 1.5)이다 — 둘레 벽은 폐기됨(10단계).
- **개구부 모서리 radius는 접선 fillet**으로만(원 꼭짓점 union=scoop ❌, `expand`=DXF 깨짐 ❌). 키 구멍(볼록)은 둥글리지 않는다.
- **plate↔PCB 3.5mm**는 스위치 핀 공간이라 고정. 키트 스탠드오프(6mm)로 못 채운다 → **별도 3.5mm 기둥 스페이서**(키트 밖). (과거엔 둘레 벽으로 채웠으나 폐기.)
- **재질 아크릴**: 직접 M3 탭 ❌ → **관통 볼트 + 끝 너트**(아크릴엔 클리어런스 Ø3.2만, 인서트도 폐기). 컷아웃 13.95는 **실측 목표값**, 레이저 kerf(~0.2mm) 보정 필요.
- export는 **2D DXF 레이어**(레이저컷). **프레임 2장(upper/lower) + 보강판 1장 + 하판 1장 = 측당 4장.** (보강판 field+ring 두 장은 폐기.)
