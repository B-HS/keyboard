# 부품 목록 (BOM) — AliExpress 구매 기준

> v3 설계(일체형 상판[베젤5.0+보강판1.5 본딩=6.5] + PCB + 하판1.5, 좌우 벽 스페이서, **M2 하단진입 볼트 → 상판 인서트**) 조립용.
> 키수 65(좌30·우35), 마운트 6/측 = **좌우 12체결**, 스태빌 약 3세트.
> 아크릴/하판/벽은 **CNC 가공**(별도 발주), PCB는 **사용자 발주**(JLCPCB, 흰색 솔더마스크). 아래는 알리에서 살 부자재.

## A. 케이스 체결 (이 설계 전용 — 필수)

| 부품                                   | 규격                         |   수량    | 알리 검색어                               |
| -------------------------------------- | ---------------------------- | :-------: | ----------------------------------------- |
| **M2 볼트** (버튼헤드)                 | M2 × **14~16mm**, 스테인리스 | 12 (50팩) | `M2 button head screw stainless`          |
| **M2 열간 인서트** (황동)              | M2, **플랜지형** 권장, L3~4  | 12 (50팩) | `M2 brass heat set insert`                |
| M2 평와셔 (선택, 얇은 보강판 압력분산) | M2                           |    12     | `M2 flat washer stainless`                |
| **고무발**                             | Ø8~~10, 높이 3~~4mm          |     8     | `rubber feet bumper self adhesive`        |
| **아크릴 접착제**(상판 본딩)           | 아크릴 솔벤트/시멘트         |     1     | `acrylic glue cement` (배송 제한 시 국내) |

> ⚠️ 볼트 길이는 **스택 18.1mm·인서트 깊이에 맞춰** 14~16에서 선택(너무 길면 솔리드 베젤에 부딪힘). 인서트는 acrylic용 열간(insert)으로, 플랜지가 보강판 위에 걸치게.

## 별도(알리 아님)

- **CNC 가공**: 일체형 상판(베젤5.0+보강판1.5=6.5)·하판1.5·벽(에어갭3.5·바텀갭5.0) — `65/export-out/*.dxf`(`bun run export:65`) 윤곽으로 발주. **cast 아크릴**(본딩·균열 고려).
- **PCB**: KiCad(`65/raw/leftplate`·`65/raw/rightplate`) → JLCPCB, 흰색 솔더마스크, 핫스왑 소켓 풋프린트.
