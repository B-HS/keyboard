# 인지 사항 — 미완성 / 공백 / 확인 필요

> split-65 **원본 생성물 분석**에서 드러난 초기 확인 사항(아래).
> ⚠️ **현재(설계 진행 후)의 미결 항목은 `docs/PROCESS.md` §6** 을 본다 (초록 표시 영역, PCB 핫스왑 소켓·M3 홀·Edge.Cuts, 레이저 kerf, 부자재 구매[긴 볼트·기둥 스페이서], 컨트롤러). 일부는 이미 결정됨: 컷아웃은 13.95 확정, 케이스 외곽은 코드가 생성(M2·축소), 결착은 **M2 관통볼트 하단진입 + 좌우 아크릴 벽**(v3) — `case-construction.md` §13.

## 1. PCB 미완성 (제조 직전 아님)

| 항목                   | 상태                                                              | 영향                                                                                       |
| ---------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 보드 외곽선(Edge.Cuts) | **좌우 모두 도형 0개**                                            | 실제 제조 치수 미확정. 추정치: 좌 약 133×95mm, 우 약 138.4×80.2mm(풋프린트 좌표 범위 기반) |
| 컨트롤러(MCU)          | **없음** (RP2040/Pro Micro 등 0개)                                | 좌우 연결·펌웨어 구동 불가 — 외부 컨트롤러/핸드와이어 전제                                 |
| 커넥터/TRRS/USB        | **없음**                                                          | 좌우 인터커넥트 미설계                                                                     |
| 스키매틱               | 사실상 빈 상태 (`parent exists but has no children`, 좌61·우73회) | 키 매트릭스 자동 스키매틱 추정이나 로그상 불명확                                           |
| RotaryEncoder          | 라이브러리 정의만 있고 미배치                                     | 로터리 인코더 미사용                                                                       |

→ 이 두 PCB는 **스위치 매트릭스 PCB만** 생성된 것. 컨트롤러는 별도 모듈로 붙여야 함.

## 2. 확인 필요한 설계 의도

- **스위치 컷아웃 13.75mm**(원본 KLE-NG 생성값; **현재 설계는 13.95** — PROCESS §2·`case-construction.md` §11) ✔️ 조사 완료: 표준 14.0보다 0.25mm 작음 → 허용오차+fit범위(13.8~14.06) 안의 **의도적 타이트 핏으로 합리적**. 단 Gateron(~13.9)보다도 작아, **CNC 금속이면 시제품 1구 끼움 테스트 + 모서리 R·디버링·챔퍼 필수**. (→ `docs/memory/cherry-mx-dimensions.md` §5)
- **좌우 비대칭**: 좌측 행2/행3이 우측보다 1키씩 적음. 의도된 split 레이아웃인지 KLE 원본 확인 필요.
- **좌측 행4 '4,3' 빈자리**: switch_28(1.25u)와 switch_29(2.75u) 사이 공백. 물리 배열 의도 확인 필요.

## 3. 연결 관계 미확인

- `keyswitch_model`(.wrl)이 PCB 풋프린트의 3D 슬롯에 **실제 매핑된 증거 없음**. 현재는 미연결 보조 자산.
- `keycaps` 뷰어는 split-65 빌드와 무관. split-65 전용 KLE 레이아웃 파일 없음.
- 서버측 오케스트레이션(KLE-NG → kbplacer 호출 드라이버)은 이 묶음에 미포함(keyboard-tools.xyz 백엔드). kbplacer 정확한 버전 번호는 로그에 없음(메시지 패턴으로 도구만 확정).

## 4. 결정 대기 (사용자에게 물을 것)

1. 이 프로젝트로 **무엇을 할 것인가** — 제조용 완성? 레이아웃 재편집? 분석만?
2. **컨트롤러 방식** — 외부 컨트롤러 보드 / 핸드와이어 / 별도 컨트롤러 PCB 추가?
3. PCB **외곽선 작성**을 진행할 것인지.
4. `keyswitch_model` 라이선스(CC BY-NC-SA, 비상업)가 사용 목적에 맞는지.
