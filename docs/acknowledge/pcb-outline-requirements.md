# PCB 외곽선 요구사항 (plate 기준)

> PCB는 사용자가 별도 작업. 이 문서는 **현재 plate(보강판) 기준으로 PCB 외곽선(Edge.Cuts)을 그릴 때의 요구사항**이다. 이 기준으로 outline을 그려 발주한다.
> v3 설계(일체형 상판 + 좌우 아크릴 벽 간격재 + M2 관통 볼트 하단진입) 전제. 치수 근거: `65/config/dimensions.js`, `65/config/layout.js`, `docs/memory/cherry-mx-dimensions.md`.

## 0. ⚠️ FDM 7.5° 틸트 개정 (2026-07-07) — **현행 발주 기준은 이 절**

> 65가 FDM(A1 mini) + M1 기둥 + **7.5° 틸트**로 전환됐다(`docs/PROCESS.md` §4.2, `65/docs/fdm-m1-case.md`). 아래 §1~5(아크릴 v3 / M2 / Ø2.4)는 아크릴 경로 보존용 — **현행 PCB는 이 절 기준으로 그린다.**

|                      | 좌 (left)              | 우 (right)             |
| -------------------- | ---------------------- | ---------------------- |
| **외곽 (Edge.Cuts)** | **146.35 × 108.25 mm** | **165.40 × 108.25 mm** |
| 중심(cx, cy)         | 57.15, −38.1           | 66.675, −38.1          |
| 코너 라운드          | R 1                    | R 1                    |

- 산식: caseOutline(키 bbox+5) + `FDM_MARGIN_EXTRA` 1.5/변. 케이스 top·plate·bottom과 **동일 외곽**(`fdmOutline`).
- **마운트홀: 6곳/측, Ø5.4 NPTH** (구 M2 Ø2.4 아님 — M1 기둥 Ø4.8이 기울어 관통: 4.8/cos7.5°+1.6·tan7.5°≈5.05 + 여유). **홀 좌표 = `SIDES[k].mountHoles` 원본 그대로**(보드 로컬 좌표. 조립 시 보드가 통째로 7.5° 기울 뿐, 코드의 `tiltY` 보정은 케이스 기둥 배치용이지 PCB 드로잉용 아님 — 혼동 금지).
- 홀 중심 ↔ 보드 가장자리 = **4.0mm**. 홀 주변 keepout: 위 칼라 Ø5.8·아래 보스 Ø6.6이 면접촉 → **반경 ~3.5 부품·트레이스 금지**.
- 스위치 좌표·피치(§2)와 핫스왑 소켓 전제는 동일 유지. 바텀갭은 앞행 3.5(소켓 1.8 대비 1.7 여유)~뒤 17.4 쐐기.
- PCB는 나사 없이 보스(아래)와 칼라(위) 사이 **무나사 캡처**(fdm-m1-case.md).

## 1. 외곽 치수 — 케이스 외곽과 동일 (M2 전환으로 축소)

> ⚠️ **v3 갱신**: M2 전환 + 컴팩트화로 **CASE_MARGIN 9 → 5** 로 축소했다. 케이스 외곽 = 키 bbox + CASE_MARGIN(5mm) 로, 일체형 상판(베젤+보강판)·PCB·하판·아크릴 벽이 모두 이 외곽을 공유한다.

PCB 외곽 = **케이스 외곽**과 동일하게 그린다 (샌드위치로 겹쳐 쌓이므로).

|             | 좌 (left)              | 우 (right)            |
| ----------- | ---------------------- | --------------------- |
| 외곽 크기   | **143.35 × 105.25 mm** | **162.4 × 105.25 mm** |
| 코너 라운드 | R 1 mm                 | R 1 mm                |
| 솔더마스크  | **흰색**               | **흰색**              |

- 산식: 키 bbox(좌 133.35×95.25 / 우 152.4×95.25) + 5mm 여백. SSOT: `65/config/dimensions.js`(CASE_MARGIN=5) + `65/config/layout.js`.
- PCB 두께 1.6mm, 핫스왑(MX) 소켓, 흰색 솔더마스크.
- PCB를 케이스보다 작게(인셋) 둘 필요는 없음. 동일 외곽 + 동일 좌표계면 스택이 정렬된다. (필요 시 −0.2mm 인셋 가능)

## 2. 좌표 원점 / 키 위치 정렬 (가장 중요)

- **PCB의 스위치 위치 = 보강판 스위치 컷아웃 중심과 동일 좌표**여야 한다. 같은 원점 + **19.05mm 피치**.
- `left.jscad` 스위치 중심 범위: X 0 ~ 114.3, Y 0 ~ −76.2 (행 0/−19.05/−38.1/−57.15/−76.2). 비표준 유닛 오프셋(2,0=1.25u 등)도 jscad 좌표 그대로.
- 기존 kbplacer 생성 PCB(`leftplate`/`rightplate`)가 이미 이 격자에 스위치를 배치 → **그 좌표계와 plate jscad 좌표계의 원점을 일치**시켜야 한다. (현재 plate outline은 translate로 보정됨: 좌 `[57.15,-38.1]`, 우 `[66.675,-38.1]` — PCB 원점 매핑 시 반영)

## 3. M2 마운팅 홀 (관통 볼트 하단진입 정렬)

- **일체형 상판 · PCB · 하판 · 아크릴 벽 전 레이어의 M2 홀이 동일 X/Y에 정렬**돼야 한다 (관통 볼트 1본이 통과).
- PCB 홀: **Ø2.4 mm**(M2 클리어런스 — PCB에 나사산 없음, 볼트는 PCB를 그냥 통과). 각 홀 주변 **키프아웃 Ø5 mm**(`MOUNT_KEEPOUT_DIAMETER`): 트랙·부품·실크 금지.
- **결착 방식(확정) = M2 관통 볼트 하단진입**: 마운트 6곳/측마다 M2 볼트가 하판 밑→위로 관통(`bottom→벽5.0→PCB→벽3.5→일체형 상판`)해, 보강판의 **플랜지형 M2 인서트**에 체결된다. PCB는 별도 나사로 잡지 않고 이 관통 볼트 + 위아래 아크릴 벽(에어갭 3.5 · 바텀갭 5.0)으로 고정·정렬된다. **베젤 윗면은 마운트 구멍·너트 0(솔리드 클린)**, 하단 볼트머리는 고무발에 은닉. → `case-construction.md`.
- **핫스왑**: PCB 하면에 Kailh MX 핫스왑 소켓 풋프린트 배치. 소켓 돌출(~~1.8~~2mm)은 PCB↔하판 5.0mm(바텀갭) 공간 내 수용.
- **확정 위치 (6개/측: 코너 4 + 좌우 변중점 2, `65/config/layout.js` computeMountHoles)**: 키 bbox를 inset = `CASE_MARGIN − MOUNT_HOLE_INSET_FROM_EDGE` (= 5 − 2.5 = **2.5**, 케이스 외곽에서 안쪽 2.5mm) 만큼 확장한 사각형의 **4 모서리 + 좌우 변 중점**. 키 영역과 케이스 외곽 사이 테두리에 위치 → 키 컷아웃과 간섭 없음.
- 정확한 좌표는 `65/config/layout.js`의 `SIDES[side].mountHoles`를 그대로 쓴다 (상판/PCB/하판/벽과 동일 좌표계).

## 4. 기타 제약

- **다이오드 면**: 다이오드가 B.Cu(뒷면)이면 PCB 하면은 하판과 5.0mm(바텀갭) 떨어지므로 SOD-123(높이 ~1.1mm) 간섭 없음. 핫스왑 소켓 ~2mm 돌출도 5.0mm 내 수용.
- **부품/트랙 엣지 클리어런스**: 외곽선에서 ≥ 0.5 mm.
- **컨트롤러/TRRS**: 현재 PCB엔 없음(외부 컨트롤러/핸드와이어 전제). 추가 시 커넥터 위치도 외곽 안에 확보.
- **스위치 마운트**: cherry-mx-basic, **핫스왑(MX) 소켓**. 소켓 풋프린트는 PCB 하면, 돌출은 5.0mm 바텀갭 공간 내 수용.
