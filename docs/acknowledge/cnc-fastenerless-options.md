# 검토안 — 인서트·스페이서 없이 4부품 CNC (부자재리스)

> 상태: **아이디에이션(미결정)**. 사용자 질문 "인서트·스페이서 없이 4개 부품을 CNC로 완벽하게 쓰는 방법". 결정되면 `case-construction.md` §13 + `PROCESS.md`로 승격.
> 전제: 현재 확정 구조 = **관통 볼트 클램프**(`PROCESS.md` §1, `case-construction.md` §12) — 프레임(1.5+1.5 2겹) + 보강판(field 1.5, 둘레벽 없음) + PCB + 하판, 인서트 0·아크릴. **이미 인서트는 없으므로**, 이 문서의 남은 쟁점은 "**간격재(너트·기둥·스탠드오프)까지 부품 형상에 통합 + 금속 직접 탭**"으로 부자재를 완전히 0으로 만들지다.

## 1. 부자재가 존재한 이유 = 레이저 평판 + 아크릴 제약

| 부자재                            | 존재 이유                       | CNC 제거 원리                                      |
| --------------------------------- | ------------------------------- | -------------------------------------------------- |
| 인서트(M3×3×4)                    | 아크릴 직접 탭 시 나사산 뭉개짐 | **금속(알루미늄) M3 직접 탭** → 인서트 불필요      |
| 스페이서(너트 2.4 / 스탠드오프 6) | 평판 레이어 간 간격 유지 불가   | **간격을 부품 형상(보스·단차·측벽)으로 일체 절삭** |

→ "부자재 0"의 필요조건: **금속 재질** + **3D 절삭으로 간격 형상 통합**. (아크릴/POM이면 탭이 약해 인서트 없이 견고 결착 어려움 → 부자재리스와 모순)

## 2. 방안 3가지

### ① 보스 샌드위치 (현 구조 최소 변경, 권장)

- 4부품 유지: frame / plate(통짜) / bottom / PCB. 확정 Z-스택 수치 그대로.
- **plate**: 알루미늄 통짜 3D — 필드 1.5 + 둘레벽 3.5 일체, 둘레벽에 M3 직접 탭(PCB 직결).
- **bottom**: 평판 + PCB 받침 보스 6mm 일체 절삭, 보스 끝 M3 탭.
- **frame**: plate에 닿는 2.4mm 단/다리 일체(너트 대체).
- 체결: 상단 frame→plate(탭), 하단 bottom 보스→PCB(탭). 부자재 0.
- 가공: plate·bottom 3D 포켓. export = plate·bottom STEP/STL, frame DXF.

### ② 트레이(monoblock tray) 마운트 (가장 견고)

- bottom + 4면 측벽 = 한 덩어리 트레이(큰 포켓 1회 가공).
- plate가 측벽 상단 단(ledge)에 안착, 측벽에 직접 탭(tray/plate mount).
- PCB는 plate 둘레 보스 또는 트레이 내부 보스에 직결. frame이 위 덮음.
- 부품: frame / plate / tray(bottom+벽) / PCB = 4개. 측벽 일체 → 강성 최고.
- 단점: 두꺼운 스톡·깊은 포켓 → 가공 시간·재료비↑, 현 구조 대비 변경 큼.

### ③ 단차 끼움(rabbet) + 코너 관통 (부품·나사 최소)

- 각 부품 외곽/홀 주변 단차(rabbet)로 위치 자결 + 간격 확보.
- 코너 긴 나사 1본이 frame→plate→bottom 전층 관통, 간격은 부품 두께/단차가 보장, 맨 아래 bottom만 탭.
- 부자재 0, 나사 수 최소, 정렬 정확. 단 단차 공차 정밀 설계 필요, 분해 시 전체 해제.

## 3. 트레이드오프

| 방안            | 부품수 | 강성 | 가공량 | 현 설계 변경 |
| --------------- | :----: | :--: | :----: | :----------: |
| ① 보스 샌드위치 |   4    |  중  |   중   |   **작음**   |
| ② 트레이        |   4    |  상  |   큼   |      큼      |
| ③ 단차 관통     |   4    | 중상 |   중   |      중      |

## 4. 결정 대기 (사용자)

1. 재질 — 알루미늄 확정?(부자재 0의 전제) / 아크릴 유지(그럼 인서트는 남김) / 기타.
2. 마운트 방식 — ① 보스 샌드위치 / ② 트레이 / ③ 단차 관통.
3. plate 통합 — 레이저 2겹(field+ring) → CNC 통짜 1개로 합칠지.

## 5. 결정 시 코드 영향 (예고)

- `plate.js`: `buildPlate3D`를 통짜(필드+둘레벽+탭홀)로, 둘레벽 홀을 탭 하경(M3 ≈ Ø2.5)으로.
- `bottom-plate.js`: 평판 → 보스 일체 3D(②면 측벽).
- `export.js`: 레이어 DXF → 3D(STEP/STL) 병행(`@jscad/stl-serializer` 이미 설치). frame만 DXF 유지.
- `dimensions.js`: 탭 하경 상수(M3 ≈ Ø2.5) 추가. (인서트 상수는 §12 관통볼트 전환 때 **이미 제거됨** — 금속 직접 탭 채택 시 불필요.)
