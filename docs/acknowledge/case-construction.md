# 인지 사항 — 케이스 적층(샌드위치) 구조 설계

> ## ⚠️ 현재 설계는 **§13** 이다 (단일 출처). 그리고 `docs/PROCESS.md`.
>
> §1~12는 **진화 이력**(H빔 → 스페이서 샌드위치 → 둘레벽+인서트 → 관통볼트 클램프 → …)이며 **현재와 다른 부분이 많다.** 현재 상태를 알려면 §13과 PROCESS.md를 본다.
>
> **현재 요약(§13)**: **일체형 상판**(베젤 5.0mm + 보강판 1.5mm 를 간격0 본딩, 6.5mm 1유닛) + 에어갭 좌우벽(3.5) + PCB(1.6, 핫스왑·흰색솔더마스크) + 바텀갭 좌우벽(5.0) + 하판(1.5mm). **에어갭 3.5 / 바텀갭 5.0 → 좌우 벽 스페이서는 갭별 2규격(3.5mm / 5.0mm).** PCB 제외 전부 cast 아크릴 **CNC**. **결착 = M2 관통 볼트 하단 진입** — 마운트 6곳/측(코너4+좌우 변중점2)에서 M2 볼트가 하판 밑→위로 관통(bottom→벽5.0→PCB→벽3.5→일체형상판)해 보강판의 **플랜지형 M2 인서트**에 체결. **베젤 윗면 = 마운트 구멍·너트 0(솔리드 클린)**, 하단 볼트머리는 고무발에 은닉. **간격재 = 좌·우 아크릴 벽 2개/갭**(에어갭 3.5 + 바텀갭 5.0, 앞뒤 개방). 컴팩트화(MOUNT_HOLE_DIAMETER 2.4, CASE_MARGIN 5) → 외곽 좌 143.35×105.25 / 우 162.4×105.25 mm. 컷아웃 13.95(CNC면 kerf 무관). export 측당 5장(bezel-5.0/plate-1.5/bottom-1.5/spacer-airgap-3.5/spacer-bottomgap-5.0, 좌우 10 DXF).

> 사용자가 알려준 split-65 물리 구조 전제. 단면 개념도: `docs/assets/case-cross-section.png`

## 1. 단면 구조 (위 → 아래)

3개 부품을 적층(샌드위치)하는 구조다.

| 색      | 부품                            | 역할                                       | 제조 방식          |
| ------- | ------------------------------- | ------------------------------------------ | ------------------ |
| 🔵 파랑 | **보강판(plate) + 외벽** 일체형 | 스위치 마운트 + 키캡 둘러싸는 테두리(외벽) | **CNC 절삭**       |
| 🟢 초록 | **PCB**                         | 스위치 매트릭스 기판                       | **JLCPCB 발주**    |
| ⚫ 검정 | **하판(bottom plate)**          | 바닥을 막는 평판                           | 단순 **직선 평판** |

## 2. 파란 부품 = H빔(I빔) 단면

보강판과 외벽이 하나의 CNC 부품으로, 단면이 **H빔처럼** 생겼다.

```
   ┃                                                      ┃     ← 외벽 (위로 솟음, 키캡 테두리/베젤)
   ┃                                                      ┃
   ┃                                                      ┃
   ┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫     ← 보강판 (수평 웹, 스위치가 끼워지는 면)
   ┃                                                      ┃     ← 외벽이 보강판 아래로도 내려와 단(ledge) 형성
   ┃ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ┃     ← 🟢 PCB (보강판 아래 공간에 안착)
   ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
  ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬   ← ⚫ 하판 (평판, 바닥 마감)
```

- **외벽(상단 플랜지)**: 보강판 위로 솟아 키캡 주변을 감싸는 벽(베젤).
- **보강판(중앙 웹)**: 여기에 스위치를 끼운다. 컷아웃은 split-65 기준 13.75×13.75mm(표준 14.0mm), 두께 1.5mm.
- **외벽 하단**: 보강판 아래로 내려와 PCB를 받치는 단(ledge)을 만들고, 맨 아래를 하판이 막는다.

## 3. 조립 스택업 (개념)

```
        키캡 (Cherry 프로파일)
          │
        스위치 (Cherry MX, 보강판에 클립 고정)
          │
   🔵 보강판/외벽  ──┐
   🟢 PCB           ├─ 파란 외벽 안쪽에 적층
   ⚫ 하판          ──┘
```

## 4. ⚠️ 검토 필요 — 보강판 ↔ PCB 간격

표준상 **Cherry MX 스위치가 보강판에 끼워지면, 보강판 하면과 PCB 상면 사이는 약 5mm**여야 한다(스위치 PCB 마운트 핀/다리가 PCB에 닿는 거리). 이 5mm 공간이 있어야 스위치가 보강판과 PCB에 동시에 결착된다.

- 개념도에서는 PCB가 보강판 바로 아래 붙어 보이지만(비례 개념도), 실제로는 **파란 외벽이 보강판 아래로 약 5mm 단을 형성해 PCB를 그 아래에 띄워 안착**시키는 구조여야 한다.
- → 정확한 간격·외벽 단 높이는 **진행 중인 Cherry MX 표준 치수 조사 결과(plate-to-PCB)로 확정**한다. (관련: `docs/acknowledge/open-questions.md`)
- → 핫스왑 소켓을 쓸 경우 PCB 아래로 소켓 높이만큼 추가 공간(하판과의 간격)도 필요.

## 5. 하판 ↔ PCB 받침 — M3 황동 스탠드오프(스페이서)

검은 하판이 PCB를 받치는 방식은 **M3 황동 스탠드오프(standoff/스페이서)**로 한다.
사용자 보유: **AIMUNOK 176pcs M3 Male-Female Hex Brass Spacers/Standoffs/Screws/Nuts Kit** (`docs/assets/spacer-kit-spec.png`, `docs/assets/spacer-kit-product.png`)

### 키트 구성 (총 176pcs, 나사경 M3)

| 종류                  |   본체 길이    | 수나사 | 수량 |
| --------------------- | :------------: | :----: | :--: |
| 암-암(F-F) 스탠드오프 |      6 mm      |   —    |  12  |
| 〃                    |     10 mm      |   —    |  12  |
| 〃                    |     15 mm      |   —    |  10  |
| 〃                    |     20 mm      |   —    |  10  |
| 수-암(M-F) 스탠드오프 |      6 mm      | +6 mm  |  12  |
| 〃                    |     10 mm      | +6 mm  |  12  |
| 〃                    |     15 mm      | +6 mm  |  10  |
| 〃                    |     20 mm      | +6 mm  |  10  |
| 팬헤드 스크류         | 6 mm (head Ø5) |   —    |  44  |
| M3 너트               |       —        |   —    |  44  |

- 스탠드오프 본체는 황동 hex(육각). 스크류·너트는 은색(스테인리스/니켈).
- **선택 가능 높이**: 단품 6 / 10 / 15 / 20 mm. M-F를 적층 체결하면 합산(예: 6+6mm body 둘을 이으면 본체 12mm) — 조합으로 중간 높이도 가능.

### 마운팅 단면 (하판 영역)

```
   🟢 PCB  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
            │  ┃ ┃              │  ┃ ┃          ← M3 스탠드오프(하판~PCB 높이 = 스페이서 길이)
            │  ┃ ┃   스탠드오프  │  ┃ ┃
   ⚫ 하판 ━┷━━╋━╋━━━━━━━━━━━━━━━┷━━╋━╋━━━━━━━━━━━━
               ▼                    ▼          ← 하판 하면에서 스크류로 체결(또는 M-F 수나사+너트)
```

- 체결: 하판 하면에서 스크류 → 하판 관통 → 스탠드오프 → PCB 나사홀 → 위에서 고정. (또는 M-F 스탠드오프 수나사를 하판에 통과시켜 너트로 고정 후 암나사 쪽에 PCB 체결)
- **스탠드오프 길이 = PCB 하면 ~ 하판 상면 거리**. 이 값이 정해지면 6/10/15/20(또는 적층)에서 선택.

### 스페이서 길이 / 외벽 단 높이 역산 (확정 치수 반영)

표준 치수 조사 완료 → 확정값(`docs/memory/cherry-mx-dimensions.md`):

- **plate 상면 → PCB 상면 = 5.0 mm** (confirmed). 이 안에 plate 두께 1.5 포함.
- **plate(=보강판) 하면 → PCB 상면 = 3.5 mm** (순수 에어갭, = 5.0 − 1.5). ← 보강판 하단을 기준으로 단을 잡을 땐 **이 값**을 쓴다.
- PCB 두께 = 1.6 mm
- 스위치 핀 PCB 하면 돌출(솔더) = 3.30 mm / (핫스왑 소켓 시) PCB 하면 소켓 돌출 ~1.8–2.0 mm
- 키캡 하단 ~18×18mm, 스커트가 plate 위 ~2mm까지 내려옴 → **외벽(베젤) 안쪽 여유는 키캡 18mm + 와블 여유 확보**

> **⚠️ 기준면 정정** (검증에서 발견): 이전 공식 `5.0 + 1.6 + 스탠드오프`는 plate 상면 기준 5.0에 plate 두께 1.5가 이미 포함돼 **중복 합산**이었다. 보강판 **하면** 기준 올바른 공식:
>
> **외벽이 보강판 하면에서 내려오는 깊이 = 3.5mm(에어갭) + 1.6mm(PCB) + 스탠드오프 길이** (하판 상면까지)
>
> = 5.1mm + 스탠드오프 길이. 여기에 하판이 외벽 하단에 체결된다.

### 보유 스탠드오프(6/10/15/20mm)로 본 권장

| 스탠드오프(PCB하면~하판) | 외벽 보강판하면 깊이 (3.5+1.6+L) | 적합성                                                                  |
| :----------------------: | :------------------------------: | ----------------------------------------------------------------------- |
|         **6 mm**         |           **11.1 mm**            | ✅ 가장 컴팩트. 솔더핀 3.3mm·핫스왑 소켓 2mm 모두 수용. **권장 기본값** |
|          10 mm           |             15.1 mm              | 컨트롤러/배선/배터리 공간 필요 시                                       |
|        15 / 20 mm        |          20.1 / 25.1 mm          | 내부 공간 많이 필요할 때만                                              |

- **순서가 핵심**: 가진 스탠드오프 길이(6 등)를 먼저 고정하고 → 거기에 맞춰 **CNC 외벽 단 깊이를 3.5+1.6+L 로 깎는다.** 외벽을 먼저 정하면 어중간한 길이가 나와 키트로 안 맞는다.
- M-F 스탠드오프(+6mm 수나사)는 적층으로 중간 높이도 가능하나, 6mm 단품으로 충분하면 불필요.

## 6. 제조 파이프라인

| 부품           | 도구         | 소스 → 산출물                                                                          |
| -------------- | ------------ | -------------------------------------------------------------------------------------- |
| 🔵 보강판+외벽 | **CNC 가공** | **`left.jscad` / `right.jscad` (SSOT)** → CNC 가공 파일                                |
| 🟢 PCB         | JLCPCB       | KiCad(`leftplate`/`rightplate`) → Gerber 발주 (Edge.Cuts 외곽선 미작성 — 발주 전 필수) |
| ⚫ 하판        | 평판 절단    | 단순 직선 판                                                                           |

> split-65는 좌/우 분리형이므로 위 구조 한 벌을 **좌·우 각각** 제작한다.

## 7. CNC 가공 — JSCAD 기준으로 CNC 파일 생성 (핵심 방향)

> **이 프로젝트의 보강판+외벽 부품은 CNC 가공이 최종 목표다. `left.jscad` / `right.jscad` 가 형상의 단일 출처(SSOT)이며, 이 JSCAD를 기준으로 CNC에 사용할 파일을 생성한다.**

### 흐름

```
left.jscad / right.jscad  (@jscad/modeling, SSOT)
   → openjscad.xyz 등에서 export
       → 메시(STL/3MF) 또는 2D 프로파일(DXF/SVG)
   → CAM (Fusion 360 / 기타)에서 가공 경로 생성
   → G-code → CNC 가공
```

- OpenJSCAD v2 export 지원 포맷: STL, 3MF, AMF, DXF, SVG, X3D, JSON.
- 3D 형상(외벽 포함 H빔)은 **STL/3MF → CAM 3D 가공**, 평면 윤곽(컷아웃·외곽)은 **DXF/SVG → 2.5D 가공**으로 뺄 수 있다.

### ⚠️ 선결 과제 — JSCAD를 H빔(외벽 포함)으로 확장

현재 `left.jscad` / `right.jscad` 는 **두께 1.5mm 평판 플레이트(스위치/스태빌라이저 컷아웃)만** 모델링한다. §1~2의 보강판+외벽 일체형 H빔 형상은 **아직 JSCAD에 없다.**

- CNC 대상은 평판이 아니라 H빔이므로, **외벽·보강판 단·스탠드오프 체결 홀까지 JSCAD에 추가**해야 CNC 소스로 쓸 수 있다.
- 확장 시 §4·§5의 치수(보강판 하면~PCB 5mm, 외벽 단 높이, M3 스탠드오프 홀, 하판 체결)를 반영한다. 정확값은 Cherry MX 표준 치수 조사 결과로 확정.

### 결정 대기 (조사 후 사용자에게 확인)

- CNC export 포맷: STL(3D) vs DXF(2.5D) — 가공 업체/CAM에 맞춰 선택.
- 소재(알루미늄/아크릴/POM 등)와 가공 공차 — 컷아웃 13.75mm 등 끼움 공차에 영향.

## 8. 설계 대안 B — 스페이서 샌드위치 (H빔 외벽 제거)

> 참조 이미지: 단면 `docs/assets/case-spacer-sandwich.png`, 평면 `docs/assets/case-top-view.png`

H빔의 세로 외벽(`l l`)을 CNC로 깎지 않고, **평면 레이어를 스페이서로 적층 체결**하는 방식.

### 부품 (위 → 아래)

| 색      | 부품                     | 형상                                                            | 가공                    |
| ------- | ------------------------ | --------------------------------------------------------------- | ----------------------- |
| 🟡 노랑 | **상판 프레임(베젤)**    | **가운데 뚫린 사각 링** — 안쪽으로 키캡/스위치 노출 ("속이 빔") | 평면(CNC/레이저/워터젯) |
| 🔴 빨강 | **스페이서(스탠드오프)** | 모서리(코너)에서 레이어 적층 체결                               | 보유 키트               |
| 🔵 파랑 | 보강판(plate)            | 스위치 컷아웃 평판                                              | 평면 가공               |
| 🟢 초록 | PCB                      | —                                                               | JLCPCB                  |
| ⚫ 검정 | 하판                     | 평판                                                            | 평면 절단               |

- 평면도(위에서): 노란 사각 링 안에 파란 보강판이 채워지고, 보강판의 스위치 컷아웃(초록)에 스위치가 박힌다. 빨간 스페이서는 **모서리**에 위치.
- **장점**: 모든 부품이 평면 가공 → CNC 단순화(H빔 단차 불필요), 레이저컷/워터젯도 가능. 스페이서로 높이 조절·분해/수리 용이. **보유 키트 활용 극대화**.
- **단점**: H빔 일체보다 강성↓(체결점 사이 처짐 가능), 모서리 스페이서 위치에 키 배치 제약.

### 스페이서 구간 (PCB 상면 = 0 기준)

| 구간                 |               거리               | 스페이서                              |
| -------------------- | :------------------------------: | ------------------------------------- |
| 상판 프레임 ↔ 보강판 |       L1 = 베젤 높이(자유)       | ✅ 키트 6/10/15/20 중 선택            |
| **보강판 ↔ PCB**     | **3.5 mm 고정** (스위치 핀 공간) | ❌ **키트 최소 6mm로 불가** → 아래 ‼️ |
| PCB ↔ 하판           |          L3 (6mm 권장)           | ✅ 키트 6mm                           |

### ‼️ 핵심 제약 — 보강판 ↔ PCB 3.5mm

표준상 **보강판 하면 ~ PCB 상면은 3.5mm 떠 있어야** 스위치가 보강판에 스냅되고 핀이 PCB에 꽂힌다. 평면도/단면도에서 파란-초록이 붙어 보여도 **실제로 붙이면 스위치가 성립하지 않는다**(보강판 1.5 + 핀 3.3 = 스위치가 4.8mm 깊이를 요구). 이 3.5mm는 키트 6mm 스페이서로 못 채운다. 처리 방법:

- **전략 1 (권장·키트로 100% 가능)**: 체결을 상·하 2개로 분리.
    - 상단: `상판 프레임 — 스페이서(L1) — 보강판` 나사 체결
    - 하단: `PCB — 스페이서(6mm) — 하판` 나사 체결
    - 보강판↔PCB는 **나사로 당기지 않고 스위치가 유지** → 3.5mm 자동 보장.
- **전략 2 (관통 일체, 더 견고)**: 모서리 긴 나사가 상판~~하판 전체 관통. 단 보강판~~PCB 3.5mm 구간에 **별도 3.5mm 스페이서 또는 보강판 일체 보스**가 필요(키트 밖).

### 베젤(L1) 높이 = 키캡을 얼마나 감쌀지

- L1 = 6mm → 낮은 베젤(스위치 하우징 정도만 감싸고 키캡은 위로 충분히 노출)
- L1 = 10mm → 키캡 측면을 더 감싸는 well 형태
- 키캡 미압 top은 PCB 위 ~18–22mm, 보강판 상면은 +5.0 → 베젤 높이는 키트 스페이서에 맞춰 정한다.

> 설계 A(H빔 일체 CNC)와 B(스페이서 샌드위치)는 택일. B가 CNC 난이도·키트 활용 면에서 유리. **채택 시 JSCAD를 "평판 보강판 + 별도 사각 프레임 + 모서리 M3 홀"로 모델링**(H빔 단차 불필요).

### ✔️ 확정 결정 (2026-06-21)

**설계 B(스페이서 샌드위치) 채택.**

- **체결: 상·하 분리** — `[상판 프레임 — 스페이서 — 보강판]` + `[PCB — 스페이서 — 하판]` 두 어셈블리. 보강판↔PCB는 나사로 당기지 않고 **스위치가 3.5mm 유지**.
- **상판↔보강판 스페이서 = 6mm** (낮은 베젤 — 키캡 하단만 살짝 감쌈). ※ 2026-06-21 갱신: 초기 10mm 깊은 well에서, 라이브 뷰 확인 후 키캡이 위로 노출되는 낮은 베젤로 변경. 보유 키트 최소값 6mm 사용.
- **PCB↔하판 스페이서 = 6mm** (솔더 핀 3.3·핫스왑 소켓 ~2 수용).

확정 Z-스택 (PCB 상면 = 0):

| 레이어              |   Z 위치    | 비고                             |
| ------------------- | :---------: | -------------------------------- |
| 상판 프레임 하면    |    +15.0    | = 보강판 상면 +5.0 + 스페이서 10 |
| 보강판              | +3.5 ~ +5.0 | 두께 1.5                         |
| (보강판↔PCB 에어갭) |     3.5     | 스위치 핀, 체결 안 함            |
| PCB                 |  0 ~ −1.6   |                                  |
| 하판 상면           |    −7.6     | = PCB 하면 −1.6 − 스페이서 6     |

- 스페이서 수량: 상단 10mm·하단 6mm 각각 코너 4~6개 × 좌우 → 키트(각 길이 F-F 12 + M-F 12 = 24개)로 충분.
- **JSCAD 모델링 방향**: ① 보강판(현 `left/right.jscad` 1.5mm 평판 + 컷아웃)에 **모서리 M3 홀 추가**, ② **상판 사각 프레임**(외곽=보강판 외곽, 안쪽 구멍=키 영역, 두께 + M3 홀), ③ **하판 평판**(+ M3 홀). 세 부품 모두 평면 → CNC/레이저컷.

## 9. PCB ↔ 보강판(Plate) 결착 — 확정

> 질문: PCB와 Plate를 어떻게 결착하나? → **나사·스탠드오프가 아니라 "스위치"가 결착 수단이다.**

### 왜 나사로 직접 못 붙이나

- 보강판 하면 ~ PCB 상면 = **3.5mm 고정**(스위치 핀 공간). 보유 스탠드오프 최소가 6mm라 이 구간엔 못 넣는다. 즉 plate↔PCB를 직접 볼트로 당길 수 없다.

### 결착 방법 — 스위치가 plate와 PCB를 묶는다

```
  키캡
   │
  [스위치]  ── 상단: 보강판(1.5mm) 컷아웃에 retention clip으로 스냅 고정
   │  └ 핀(3.3mm) ── 하단: PCB 홀에 삽입 → 납땜(or 핫스왑 소켓)
  PCB
```

- **Cherry MX PCB 마운트(5핀)** 사용: 중앙 보스 + 금속핀 2 + **플라스틱 고정다리 2**가 PCB에 박혀 plate-PCB를 견고히 정렬·고정.
- **납땜 권장**(최대 강성). 핫스왑 소켓도 가능하나 plate-PCB 결합 강성은 납땜보다 약함.
- 결과: **보강판 + 스위치 + PCB가 하나의 강체 샌드위치**가 된다. 3.5mm 간격은 스위치 본체가 유지.

### 케이스 전체 체결 사슬 (한 몸)

```
프레임 ─(6mm 스탠드오프)─ 보강판 ─(스위치)─ PCB ─(6mm 스탠드오프)─ 하판
```

- 상단 스탠드오프: 프레임↔보강판 (M3, plate에 체결).
- 하단 스탠드오프: PCB↔하판 (M3, PCB에 체결).
- 두 스탠드오프는 **같은 모서리 M3 홀(plate·PCB 동일 좌표)에서 동축**. plate↔PCB 3.5mm 구간엔 나사가 지나가지 않음(상단은 plate에서, 하단은 PCB에서 멈춤) → 간섭 없음.
- 따라서 plate↔PCB의 유일한 결착은 스위치, 전체는 `프레임–plate–스위치–PCB–하판`으로 직렬 연결된 한 몸.

### ✔️ 확정 (2026-06-21) — 핫스왑 + 플레이트 일체형 보스

> 사용자: PCB에 **핫스왑 소켓**을 단다. 핫스왑이면 스위치가 빠지므로 스위치-홀드(전략1/§8)로는 강성 부족. → **plate↔PCB를 직접 결착**한다.

- **방식: 플레이트 일체형 보스 (CNC)**. plate를 **5mm 소재**에서 가공: 키 영역은 1.5mm로 파내고, **8개 모서리 마운트 홀에 3.5mm 보스(Ø7)를 남겨** PCB 상면까지 내려오게 한다. 보스에 **M3 탭** → PCB를 아래에서 나사로 올려 보스에 직접 체결.
- 효과: **plate + PCB가 보스로 직접 볼트 결합** → 핫스왑 스위치와 무관하게 강체. 3.5mm 간격은 보스가 유지.
- 전체 체결: `프레임 —6mm 스페이서— plate(보스) —PCB— 6mm 스페이서— 하판`. plate↔PCB는 보스, 나머지는 키트 스페이서.
- **제조 변경**: plate가 **2D 평판 → 3D 가공품**이 됨. CNC는 5mm 스톡 3D 포켓팅(필드 1.5mm + 보스). export는 **STL/3MF(3D)** 사용(DXF는 필드 윤곽 참고용). 프레임·하판은 여전히 평판(DXF).
- 모델: `65/parts/plate.js` `buildPlate3D` = 필드(1.5mm) ∪ 보스 8개(Ø7, 3.5mm, M3 보어). plate3D Z범위 −3.5~1.5 확인.
- PCB 작업: 모서리 M3 홀(Ø3.2)은 **아래에서 보스로 올려 체결**하는 용도 (→ `pcb-outline-requirements.md`). 핫스왑 소켓 풋프린트도 PCB에 배치.

## 10. 보강판 보스 → 둘레 벽 (2026-06-21) — (이력, §12로 대체됨)

> ⚠️ **이력**: 한때 현재 구조였으나 **§12(관통 볼트 클램프)로 대체됨.** 둘레 벽은 폐기, 보강판은 평판 1겹으로 복귀. §9의 "보스(Ø7 원기둥 8개)"는 이 섹션이 대체했었고, 다시 §12가 대체. (프레임·하판·간격재 개념은 유지)

### 변경

- 사용자: **노란 상판·검은 하판은 그대로.** 보강판(파란)의 **8개 둥근 보스 → 4면 둘레 벽**으로. ("원 깎지 말고 벽" = CNC상 둥근 보스보다 둘레 벽이 가공 쉽고 견고)

### 구성 (그대로 유지 + 보스만 벽으로)

```
🟡 상판 프레임 (베젤)
   ┊ 프레임↔보강판 스페이서 = M3 너트 ~2.4mm (스탠드오프 최소 6mm보다 작게, 낮은 베젤)
🔵 보강판 = 필드 1.5mm + 둘레 벽(아래 3.5mm) ← 보스 8개를 대체한 연속 벽, PCB까지
🟢 PCB  ← 보강판 둘레 벽에 아래서 나사 체결(핫스왑)
   ┊ M3 스탠드오프(스페이서) 6mm  ← PCB↔하판 (키트)
⚫ 하판
```

- **보강판 둘레 벽**(`65/parts/plate.js buildDownWall`): 케이스 외곽에서 안쪽 4mm 두께 링, 필드 아래로 3.5mm 내려가 PCB 상면에 닿음. plate3D Z범위 −3.5~~1.5(벽 −3.5~~0, 필드 0~1.5) → 배치 시 월드 0(PCB top)~5.
- **결착**: PCB를 보강판 둘레 벽에 아래에서 M3 나사로 체결(벽에 탭). 핫스왑이라 스위치는 구조재 아님 → 둘레 벽이 plate-PCB 강체 결합.
- 프레임↔보강판 = **M3 너트 ~2.4mm**(키트 스탠드오프 최소 6mm보다 작은 스페이서). 너트 2개면 ~4.8mm. PCB↔하판 = M3 스탠드오프 6mm.
- 제조: 보강판은 3D(필드+둘레 벽), 약 5mm 스톡 포켓팅 → STL/3MF. 프레임·하판은 평판(DXF).

### 뷰어 (`case-meshes.js`)

- 렌더: 하판·PCB·보강판(둘레 벽)·프레임·스페이서(원기둥)·스위치·키캡. 토글 7개. 좌+우 동시.

### 기타 (유지)

- 키캡↔외벽 클리어런스 1.25mm. 키캡 폭 X 스케일 보정(1.25U CapsLock/Enter 정상).
- **상판 프레임 개구부 = 키 셀 합집합**(`top-frame.js buildOpening`): 각 키 셀(사각, 폭 = u·19.05 − 1.05 + 2·클리어런스)의 union → 프레임이 키 클러스터 실루엣을 따라가며 **키 없는 틈(빠진 4,3 자리·스태거드 가장자리)을 노란색으로 덮음**. 파란 보강판은 키 사이 얇은 선에만 노출.
- **개구부 모서리 radius**(`GAP_FILLET=1.0`, `filletOutline`): 키 클러스터 실루엣(개구부 outline)의 모든 모서리를 **두 변에 접하는 호(접선 fillet)** 로 둥글게 — 틈 머리(볼록 코너)·외곽 코너 모두 매끄러운 radius. 키캡은 구멍 안 객체라 영향 없음(키 구멍 형상 안 둥글어짐). ※ 원을 꼭짓점에 union하면 scoop처럼 파먹혀 ❌, expand(모폴로지)는 DXF 깨짐 ❌ → 직접 접선 fillet 후 `geom2.fromPoints`로 재구성.
- 상판 프레임↔보강판 스페이서 = M3 너트 ~2.4mm (BEZEL_SPACER).

## 11. 재질 = 아크릴 (PCB 제외) — 2026-06-21

> 사용자: **PCB만 빼고 전부 아크릴**(상판 프레임·보강판·하판 모두 아크릴).

### 결착 시사점 (아크릴은 직접 탭 약함)

- **보강판 둘레 벽(아크릴 3.5mm)에 M3 직접 탭 ❌** — 아크릴은 나사산이 쉽게 뭉개짐. 대안:
    - **열간 압입 인서트(brass M3 insert, short ~3mm)** 를 벽에 박고 나사 체결 — 권장.
    - 또는 **셀프태핑 나사**(반복 분해엔 약함).
    - 또는 **관통 볼트 + 너트**: PCB 아래에서 볼트가 벽(클리어런스 홀)을 지나 위에서 너트 — 단 벽 위는 plate 필드라 너트 공간 확보 어려움 → 인서트가 현실적.
- 프레임↔보강판·PCB↔하판은 M3 너트/스탠드오프로 클램프(아크릴은 클리어런스 홀만 뚫음, 나사산은 금속 스탠드오프/너트가 담당).

### ✔️ 인서트 확정 (2026-06-21) — 보유 키트 M3×3×4 ⚠️(§12에서 폐기됨)

> ⚠️ **이력**: 아래 인서트 압입안(둘레벽 Ø3.8)은 **§12 관통 볼트 클램프로 대체·폐기됨.** 현재는 인서트 0, 모든 아크릴 Ø3.2 클리어런스. 아래는 폐기된 검토 기록이다.

> 사용자 보유: 220pcs 황동 열간압입 인서트 키트(M2/M2.5/M3/M4/M5/M6, 표기 = `M나사 × 길이 × 외경`).

- **채택: M3×3×4** (나사 M3 · 길이 3 · OD 4). 둘레벽 3.5mm에 길이 3 매립(여유 0.5mm) → field 1.5mm가 위를 덮어 **블라인드 홀**. 좌우 16개 필요 < 보유 25개. (M3×4×4는 길이 4 > 벽 3.5라 ✗)
- **ring 레이어 홀 = 압입경 Ø3.8**(OD4−0.2, `INSERT_HOLE_DIAMETER`). frame·field·bottom·PCB 홀은 클리어런스 Ø3.2(`M3_HOLE_DIAMETER`) 유지 — `mountHoleCuts(holes, diameter)`로 분리.
- **마운트홀을 둘레벽 폭(`PLATE_WALL_THICKNESS` 6mm) 정중앙으로 이동**(inset = CASE_MARGIN − 벽/2 = 6.0). 압입부 안쪽/바깥 살 각 **1.1mm**(이전 inset 5.125에선 안쪽 0.22mm로 아크릴 크랙 위험).
- ⚠️ 아크릴 열압입은 크랙 위험 → **예열·저속 압입, 압입경 실측 보정**(제조사 데이터시트 우선). 압입 방향은 ring 한쪽 면에서 Z축으로.

### 제조 (확정) — 보강판 = 레이저컷 2겹 적층 (더 싼 쪽)

- **보강판 = 레이저컷 2겹 적층**: **1.5mm 플레이트(컷아웃·필드) + 3.5mm 링(둘레 벽)** 을 접착/볼트로 합침. (CNC 밀링보다 저렴·정밀 — 사용자 선택)
- 프레임(3mm)·하판(3mm)은 평판 1겹 레이저컷.
- 둘레 벽(3.5mm 링)에 PCB 체결 → 아크릴이므로 **열간 인서트** 권장.
- **frame 개구부 접선 fillet**(`GAP_FILLET=1.0`)은 아크릴 응력집중(크랙) 완화에도 유리.

### ✔️ 스위치 컷아웃 = 13.95mm (확정, 레퍼런스 기반)

- **13.95mm** 채택. 근거:
    - Cherry 공식 컷아웃 = 0.551 ±0.002 in = **13.9954 ±0.0508mm** → 13.95는 규격 공차의 "타이트" 쪽 끝. (`docs/reference/cherry-mx-sources.md`)
    - geekhack 59837 (40W 레이저, **6mm 아크릴 실측**): 14.0에서 **−0.05mm = 13.95** → "단단한 솔리드 핏, 키캡 빼도 스위치 안 빠짐". 정확히 "딸깍 스냅" 목표값.
- ⚠️ **레이저 kerf 보정**: 레이저는 그은 선보다 ~0.2mm 넓게 잘림 → 13.95 **실측**을 원하면 도면은 그보다 ~0.2mm 작게 그리거나(≈13.75) **레이저 소프트웨어에서 kerf 보정**. 모델/DXF는 **설계 목표값 13.95** 로 두었으니, 발주 시 가공 업체에 소재(아크릴)·실측 13.95 전달해 kerf 보정 확인.

### export — 레이어별 2D DXF (레이저컷) ⚠️(레이어 구성은 §12로 갱신됨)

- `bun run export` → `export-out/{측}-{레이어}-{두께}mm.dxf` (좌·우 각 4장 = 8장).
- ⚠️ **현재 레이어**(§12): `frame-upper-1.5mm`, `frame-lower-1.5mm`, `plate-1.5mm`, `bottom-3mm`. (아래의 plate-field/plate-ring/frame-3mm는 둘레벽·단일프레임 시절 = 폐기.)
- (폐기) 구 레이어: `frame-3mm`, `plate-field-1.5mm`, `plate-ring-3.5mm`, `bottom-3mm`.

## 12. (이력) v2 관통 볼트 클램프 — §13으로 대체됨

> ⚠️ **이력**: v2 관통 볼트 클램프(인서트 0)는 **§13(일체형 상판 + M2 하단진입 볼트 + 좌우 벽)으로 대체됨.** 한때 현재 구조였다. 유지된 개념: 재질=아크릴, 프레임 개구부=키 실루엣+접선 fillet, 컷아웃 13.95. 아래는 폐기된 v2 기록이다.

### 변경 동기

- 둘레벽(§10) + 열간 인서트(§11)는 **아크릴 열압입 크랙 위험** + 보강판 3D(2겹 적층) 가공·정렬 부담이 컸다.
- → 인서트 없이 **관통 볼트 클램프**로 단순화. 보강판은 평판 1겹으로 복귀, 모든 아크릴은 클리어런스 홀만, 나사산은 맨끝 너트 1개가 전담.

### 결착 = 관통 볼트 1본 × 8 (모서리)

```
  [볼트머리]  ── 프레임 위층 Ø6 카운터보어에 매립 (상면 평탄)

  [끝 너트]   ── 하판 아래(고무발 쪽)에서 전 스택을 압착
```

- **모든 아크릴 층 = 클리어런스 Ø3.2**(`M3_HOLE_DIAMETER`). 나사산을 아크릴에 직접 내지 않음 → 크랙·풀림 회피.

- **간격재가 각 층 거리를 유지**(볼트 장력을 받아냄): 프레임↔보강판 너트 2.4 / 보강판↔PCB 기둥 3.5 / PCB↔하판 스탠드오프 6. 핫스왑이라 스위치는 구조재 아님 → 기둥 스페이서가 plate↔PCB 3.5 보장.
- 볼트 길이 ≈ 스택 21.0mm(+10.4 ~ −10.6) + 끝너트·여유 → **~24mm급 M3**.

### 상판 프레임 = 2겹 레이저컷 (볼트머리 매립)

- 프레임(3mm)을 **1.5 + 1.5 두 장**으로 나눠 레이저컷: 위층 = 볼트머리 자리 Ø6(`BOLT_HEAD_DIAMETER`), 아래층 = 샤프트 Ø3.2. 적층하면 카운터보어가 되어 머리가 묻히고 상면 평탄.
- 코드: `top-frame.js` `buildTopFrameLower2D`(Ø3.2) / `buildTopFrameUpper2D`(Ø6) / `buildTopFrame3D`(아래+위 각 1.5 적층). export = `frame-lower-1.5mm` + `frame-upper-1.5mm`.

### 마운트 홀 위치

- `layout.js computeMountHoles`: 키 bbox에서 inset = `CASE_MARGIN − MOUNT_HOLE_INSET_FROM_EDGE` = 9 − 3 = **6.0** 확장한 사각의 4모서리 + 4변중점 = **8개/측**. (둘레벽이 없어진 지금은 "케이스 외곽에서 안쪽 3mm" 의미. 수치 6.0은 이전 둘레벽 정중앙과 우연히 동일.)
- 전 레이어가 `side.mountHoles` 공유 → 정렬 보장. (PCB·하판도 동일 좌표 → `pcb-outline-requirements.md`.)

### 제조 (현재)

- 전 부품 **평판 레이저컷**(아크릴): frame-upper(1.5)·frame-lower(1.5)·plate(1.5)·bottom(3). 보강판이 1겹 평판으로 돌아와 3D 가공 불필요.
