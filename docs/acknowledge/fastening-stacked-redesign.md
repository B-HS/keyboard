# 결착 재설계 — stacked 아크릴 / 표준오프 샌드위치 (검토안)

> 상태: **검토안(사용자 결정 대기)**. 사용자 목표: 아크릴을 전부 "단일 평판(1자판) + 구멍만"으로, PCB 포함 **최대한 단순하게 결착**. (3장 고정 아님 — stacked로 층이 늘어도 무방.)
> 트리거 레퍼런스: **CannonKeys stacked acrylic** (https://docs.cannonkeys.com/stacked/stacked_build/).
> 근거: 리서치 워크플로우(마운팅 스타일·아크릴 샌드위치·3.5 제약·현행 점검) + Cherry MX 1차 데이터시트. 결정되면 `case-construction.md` §13 + `PROCESS.md`로 승격.

---

## 1. 현행 점검 (관통 볼트 클램프, `case-construction.md` §12)

| 부품        | 현재                                              | "단일 평판+구멍" 부합? |
| ----------- | ------------------------------------------------- | ---------------------- |
| 상판 프레임 | **1.5+1.5 2겹 카운터보어**(위층 Ø6 볼트머리 매립) | ❌ 유일한 비평판 요소  |
| 보강판      | 1.5mm 단일 압출 + 컷아웃 + Ø3.2                   | ✅ 이미 평판           |
| 하판        | 3mm 단일 + Ø3.2                                   | ✅ 이미 평판           |
| 스페이서    | **3종**: 너트 2.4 / 기둥 3.5 / 스탠드오프 6       | △ 번잡                 |

- **위반은 상판 1군데**(2겹 카운터보어)로 국소화됨. plate·bottom은 손댈 것 없음.
- 스페이서 3종 중 **2.4(베젤)만 자유 변수**. 3.5(스위치 핀 공간)·6(소켓 돌출)은 **물리적으로 강제** → 평판으로 못 메움(Cherry 도면: plate상면→PCB 5.0 − plate 1.5 = 3.5 고정).

---

## 2. 🔑 결정적 발견 — 3.5mm는 "비표준"이 아니다

핫스왑 PCB↔보강판(1.5)의 **정확히 그 3.5mm**를 메우는 **스톡 부품이 존재**한다:

- **CustomKBD "M2 screw/stand-off kit for hot-swap PCBs"**: `M2-3mm 플랫헤드 ×13 / M2-3mm 접시 ×13 / M2-3.5mm 스크류포스트(니켈도금 구리) ×13`. 명시: _"hot-swap PCB and 1.5mm plate 지원"_.
- **eBay "M2×3.5mm Hex Standoff for Hotswap Cherry MX"**: _"PCB와 plate 간격 확보용… M2 나사라 **스위치 4개 사이 코너에 들어감**"_.

→ 두 가지 의미: ① 3.5 갭은 전용 부품 그대로 해결(가공·와셔 보정 불필요). ② **스위치 사이 내부에 배치 가능** → 둘레 8곳 외에 **필드 내부 지지점**을 추가해 **얇은 plate 처짐을 잡고 plate↔PCB를 촘촘히 결속**. 핫스왑 보드의 표준 수법.

---

## 3. CannonKeys "stacked" 점검 — 무엇을 빌리고, 무엇을 바꿔야 하나

**구조**: 케이스 7겹 + 발 4겹, 전부 **납작한 아크릴 링/판**. M2 스크류 + M2 표준오프(대/소). 바닥 표준오프가 위로, 위층을 내려 끼워 조임. **간격·벽을 금속이 아니라 "납작 아크릴 링 레이어"로 만든다.**

**✅ 빌릴 것**: 모든 층 = 납작 평판/링 + 구멍, 카운터보어 0, 표준오프+짧은 스크류로 층마다 끊어 체결(분해 용이). 이게 사용자 목표와 정확히 일치.

**⚠️ 반드시 바꿀 것 (핫스왑)**: CannonKeys 가이드는 **납땜 빌드** — 스위치가 plate+PCB를 한 몸으로 솔더링해 **간격을 스위치가 유지**, 둘 사이에 링 불필요. **split-65는 핫스왑** → 스위치가 plate-PCB를 못 묶음 → **plate↔PCB 3.5를 별도(아크릴 링 또는 M2×3.5 포스트)로 반드시 결속**해야 함. 이게 원본과의 결정적 차이.

---

## 4. 마운팅 스타일 결론 (리서치)

split-65 구조 = 업계 용어로 **샌드위치/플레이트 마운트** — 레이저컷 아크릴에 **가장 자연스러운 정통 방식**. tray/top/bottom/gasket은 전부 돌출 보스·채널(3D 형상)을 요구해 평판과 불합. plateless는 핫스왑에서 강성·유지력 최약(5핀 필수) → 비권장. **샌드위치가 정답.**

---

## 5. 두 가지 추천 노선 (둘 다 전부 평판+구멍, 핫스왑 정합)

### 노선 A — 표준오프 샌드위치 (간격재 = 금속 표준오프) ★ 1순위 추천

```
🟡 상판 베젤 (아크릴 3mm 평판, 개구부+Ø2.4)
   ─ (베젤 간격) ─
🔵 보강판 (아크릴 1.5mm 평판, 스위치컷+Ø2.4)
   ─ 3.5 ─  ← M2×3.5 핫스왑 스크류포스트 (둘레 8 + 필드 내부 2~4)
🟢 PCB
   ─ 3.5~6 ─  ← M2/M3 표준오프
⚫ 하판 (아크릴 3mm 평판, Ø2.4)
```

- 간격 = **금속 표준오프**가 담당. **아크릴은 3장(측당)** 그대로, 카운터보어 0.
- plate↔PCB = M2×3.5 스크류포스트(둘레+**필드 내부**) → 처짐 억제·강한 결속.
- 체결 = standoff chain(층마다 짧은 M2 스크류 양면). 머리는 **하판 밑(고무발) + 상단 캡** 또는 버튼헤드 노출.
- 장점: 아크릴 최소(3장), 강성↑(내부 포스트), 부품 전부 스톡, 분해 쉬움. 총높이 ~16mm로 컴팩트 가능.
- 단점: 스택 안에 금속이 보임(숨겨짐), 베젤 낮으면 키캡 하단 틈(저프로파일감).

### 노선 B — 올-아크릴 stacked (간격재 = 아크릴 링 레이어) — CannonKeys 룩

```
🟡 상판 베젤 (3mm)
🔵 보강판 (1.5mm)
🟦 간격 링 3.5mm (둘레 프레임=벽)      ← 아크릴, plate↔PCB 갭
🟢 PCB
🟦 간격 링 (둘레 프레임, USB 컷)        ← 아크릴, PCB↔하판 갭
⚫ 하판 (3mm)
```

- 간격·벽 = **납작 아크릴 링**이 담당(금속 표준오프 0). 관통 볼트가 전층 클램프.
- 장점: **전부 아크릴**(외관·소리 일관, CannonKeys 적층 룩), 금속 노출 0.
- 단점: 층 ↑(링 2장 추가), 지지가 **둘레만**이라 plate 처짐 우려(필드 내부 지지 없음), 관통 볼트 정렬.
- ※ 핫스왑이라 링만으론 plate-PCB가 안 묶임 → **관통 볼트가 3.5 링을 지나 클램프**(필수). 원하면 노선 A의 내부 M2×3.5 포스트를 일부 병용해 처짐 보완(하이브리드).

### (옵션) 하이브리드 — A의 결속 + B의 외관

표준오프로 결속(A)하되, 케이스 **측면에 얇은 아크릴 링/스커트 레이어**를 덧대 stacked 적층 룩(B)을 연출. 구조는 A, 외관은 B.

## 6. 비교표

| 항목          | 현행(§12)     | 노선 A(표준오프)          | 노선 B(아크릴 링) |
| ------------- | ------------- | ------------------------- | ----------------- |
| 아크릴 층(측) | 4 (상판 2겹)  | **3**                     | 5 (링 2장+)       |

| 외관          | 혼합          | 금속 보임                 | **전부 아크릴**   |

| 부품 표준성   | 3.5 기둥 별도 | **M2×3.5 스톡**           | 아크릴(자작)      |

## 7. 추천

**1순위: 노선 A (표준오프 샌드위치) + M2×3.5 핫스왑 스크류포스트 + 필드 내부 지지점.**

- 이유: 핫스왑 강성 문제(노선 B의 약점)를 **내부 포스트로 정면 해결**, 부품 전부 스톡, 아크릴 최소, 분해 용이. 리서치가 꼽은 정통 샌드위치 그대로.
- CannonKeys 적층 **룩**을 원하면 → **하이브리드**(측면 아크릴 링 추가)로 외관만 입힘.
  **2순위: 노선 B** — "무조건 전부 아크릴·금속 0·stacked 룩"이 최우선이고 plate 약간의 유연함을 감수할 때.

## 8. 결정 필요 (사용자)

1. **노선**: A(표준오프, 강성·최소) / B(아크릴 링, 올아크릴 룩) / 하이브리드.
2. **나사 규격**: **M2**(3.5 스톡 포스트 활용, 단 홀 주변 살 얇음→마운트홀 안쪽 이동) / M3(강도 여유, 단 3.5는 와셔 보정).
3. **볼트 방향/머리**: 하판 밑 숨김+상단 캡 / 양면 버튼헤드 노출.
4. **필드 내부 지지점**: 스위치 사이 M2×3.5 포스트 추가 여부(분리형 폭 넓어 권장).
5. **베젤 높이**: 낮게(키캡 노출, 저프로파일) / 높게(키캡 감쌈, 상판 두껍게).

> ※ 결정 전까지 코드(현행 §12)는 변경하지 않음. 결정 후 해당 노선으로 `dimensions/top-frame/export/case-meshes` 수정 + 문서 승격.

## 9. ✔️ 사용자 선택 반영 — 확정 방향 (2026-06-25): **오픈 사이드레일 stacked**

사용자 결정:

- **앞·뒤(위아래) 벽 개방 / 좌·우(양옆)만 벽** → 스페이서를 풀 링이 아니라 **좌우 사이드 레일**로. 앞뒤는 층이 떠 보이는 stacked 개방감.
- **나사 = M3**(보유) → 3.5mm 간격을 **3.5mm 아크릴 사이드 레일**로 해결(M2×3.5 금속 포스트 불필요). PCB↔하판은 아크릴 레일 또는 보유 M3 6mm 스탠드오프.
- **상단에 볼트 머리 비노출** → 볼트는 **하판 밑에서 위로**, 머리는 고무발에 은닉. 상단은 **얇은 캡 레이어**로 너트를 덮어 상면 클린.
- **둘레만**(내부 지지점 없음) → 좌우 레일에서만 체결.

### 스택업 (PCB 상면=0, 전부 평판 아크릴 + Ø3.2 구멍)

```
( 얇은 캡 레이어 ~1.5mm )   ← 상단 너트 은닉, 상면 클린
🟡 상판 베젤판 3mm           (full 평판, 키캡 개구부)
🟦 베젤 레일 (좌·우)         아크릴 strip, 높이=베젤갭(자유, 예 3mm)   ┐ 앞뒤
🔵 보강판 1.5mm              (full 평판, 스위치 컷)                    │ 개방
🟦 3.5 레일 (좌·우)          아크릴 strip 3.5mm (HARD 에어갭)          │ (벽
🟢 PCB 1.6mm                (핫스왑)                                  │  없음)
🟦 갭 레일 (좌·우)           아크릴 strip ~5~6mm (소켓+배선 여유)      ┘
⚫ 하판 3mm                  (full 평판)
( 고무발 )                  볼트 머리 은닉
```

- **사이드 레일**: 좌·우 각각 케이스 전후 길이로 뻗은 아크릴 막대. 양옆이 벽이 되고 앞뒤는 열림. 각 레일은 관통 볼트 2개 이상이 위치를 잡음.
- **결착**: M3 볼트가 하판 밑→위로 좌우 레일 기둥을 관통, 상단에서 M3 너트로 마감 → 그 위를 얇은 캡 레이어가 덮어 머리·너트 비노출. 볼트 길이 ≈ 스택 ~21.6mm + 여유 → **M3 ~25mm**(별도 구매). 아크릴은 전부 Ø3.2 클리어런스(나사산 없음).
- **마운트 위치**: 좌·우 레일만 (앞/뒤 변중점 홀 폐기). 측당 ~6점(좌3·우3: 앞코너·중앙·뒤코너).
- **층 수**: 측당 아크릴 ~8장(캡+베젤판+베젤레일L/R는 1파트 취급+보강판+3.5레일+PCB자리+갭레일+하판). 전부 평판 레이저컷, 카운터보어 0.

### ⚠️ 짚어야 할 트레이드오프 — 앞뒤 개방 + 내부 지지 0 = plate/PCB 전후 처짐

- 보강판·PCB가 **좌·우에서만 지지**되고 앞뒤가 열려 있어, 분리형 반쪽(전후 ~95mm)을 가로질러 **타건 시 중앙이 앞뒤로 휠** 수 있음(1.5mm 아크릴 plate + 1.6mm PCB). 약하면 "개스킷 같은 유연감", 심하면 "물렁/불안정".
- 사용자 선택(개방감·둘레만) 우선이므로 **그대로 진행 가능**. 다만 완화책(개방 룩 최대 보존):
    - (a) **하판 1겹만 앞뒤 닫기**: 맨 아래층 front/back에 낮은 살을 남겨 베이스만 보강(위층 개방감은 유지).
    - (b) plate/PCB를 살짝 두껍게(plate는 스냅 위해 1.5 고정이라 어려움 → PCB·하판 위주).
    - (c) 그대로 수용(유연감 의도).

### 코드 변경 개요 (확정 시)

- `top-frame.js`: 2겹 카운터보어 폐기 → 단일 평판 1겹(Ø3.2). `BOLT_HEAD_DIAMETER` 제거.
- `parts/` 신규: 사이드 레일(좌·우 strip) 빌더 + 캡 레이어. `dimensions.js`에 레일 두께(베젤/3.5/갭) 상수.
- `layout.js`: 마운트홀을 좌·우 레일 위치로(앞/뒤 변중점 제거). inset 재설정(M3 살 확보).
- `export.js`: 레이어 = 캡 / 베젤판 / 베젤레일 / 보강판 / 3.5레일 / 갭레일 / 하판 (측당 ~7 DXF).
- `case-meshes.js`: buildSpacers를 사이드레일+하판밑 볼트머리+상단 너트/캡 렌더로.

### ✔️ 구현 완료 (v3 브랜치, 2026-06-25) — **일체형 상판 + 하단진입 관통볼트**

> 진화: 오픈 사이드레일 → 캡 제거 → **사이드 레일·O-ring(§11)도 폐기**, 사용자 제안 "일체형 보강판 + 일자 관통" 채택. **스위치가 plate↔PCB 3.5를 span**하므로(§11 재발견) 벽·다양한 스페이서 불필요.

- **구조**: `하판 - PCB - 일체형 상판(베젤+보강판 본딩)`. 베젤(**5.0mm**)이 보강판(1.5mm) 위에 **간격 0으로 직접 적층** → 일체형 1유닛 **6.5mm**(cast 아크릴 솔벤트 용접 전제). 베젤을 5.0로 올려 키캡 스커트 하단(plate+2≈+7.0)을 베젤 상단(+10.0)이 ~3mm 감쌈.
- **결착**: 마운트 6곳마다 M2 볼트가 **하판 밑→위로** 관통(bottom→벽5.0→PCB→벽3.5→상판)해 일체형 상판의 **플랜지형 M2 인서트**에 체결. **베젤(윗면)은 마운트 구멍 없음 = 솔리드 클린**(`buildTopFrame2D`에서 mountHoleCuts 제거, bezel poly 1560→384). 보강판(아랫면)에만 인서트 구멍 — 인서트 플랜지가 보강판 위에 걸치고 베젤이 덮어 클램프 인장(아래로 당김)을 플랜지가 받음. 하단 머리는 고무발 은닉, **상단 너트·구멍 0**.
- **갭/클램프 하중**: plate↔PCB 3.5는 필드에선 스위치가 유지, **마운트 6곳엔 스페이서**(클램프 하중을 스위치 대신 받음). PCB↔하판은 **5.0mm 스페이서**(바텀갭 = 핫스왑 소켓 ~2mm+여유). **에어갭 3.5 / 바텀갭 5.0 → 좌우 벽 스페이서가 두 규격(3.5·5.0mm)**. **둘 다 둥근 와셔(특주)가 아니라 케이스 외곽 곡률에 맞춘 "코너/엣지 아크릴 블록"**(`parts/spacer.js`, 사각 ∩ 외곽) → 같은 레이저 발주에 끼워 cut, **특주 0·외관 일관**.
- **M2 전환 + 케이스 축소**: `MOUNT_HOLE_DIAMETER=2.4`(M2; 구 M3_HOLE 3.2 폐기), `CASE_MARGIN 9→5`, `MOUNT_HOLE_INSET 3→2.5`. → 케이스 좌 151.35×113.25 → **143.35×105.25**, 우 170.4 → **162.4×105.25** (각 변 −8mm). CannonKeys stacked도 M2 사용. 기본값 `PLATE_BOTTOM_TO_PCB_TOP=3.5`·`BOTTOM_GAP=5.0`·`TOP_FRAME_THICKNESS=5.0`, 스택 **18.1mm**(topFrameTop +10.0 ~ bottomBottom −8.1), stemTop +16.6. `BEZEL_GAP`·`RAIL_WIDTH` 제거.
- 마운트홀 좌·우 **6점/측**(코너4+좌우변중점2). 파일: `side-rail.js`·`cap.js` 삭제, `parts/spacer.js` 신설. `case-meshes.js` buildHardware(코너블록 스페이서 + M2 인서트·볼트), `top` 그룹(베젤+보강판).
- export 측당 **5장**: `bezel-5.0 / plate-1.5 / bottom-1.5 / spacer-airgap-3.5 / spacer-bottomgap-5.0` (좌우 10 DXF). **스페이서까지 전부 레이저컷 아크릴**, 볼트·인서트만 부자재(M2).
- 뷰어 토글 7: 상판(베젤+보강판 일체) / PCB / 하판 / 스페이서 / 볼트 / 스위치 / 키캡 (+Zen 65 비교·투명도 슬라이더 80%).
- 검증: `bun run smoke:65`(holes 6, 스택 18.1mm) · `bun run build`(OK) · 뷰어 렌더(일체형 상판·개방 측면·하단 6볼트머리·코너 스페이서, 콘솔 에러 0) 통과.
- ⚠️ 미확정: 일체형 상판 본딩(cast 아크릴 솔벤트) 디테일, 점 스페이서 재질(아크릴 와셔 vs 나일론). 베젤 높이(5.0 키캡 감쌈)·바텀갭(5.0 소켓 여유)은 확정. 확정 시 `case-construction.md §13` + `PROCESS.md` 승격 + v3 커밋.

> O-ring 가스켓(§11·소싱 리서치 완료)은 **이번엔 폐기**. 필요 시 스펙: 실리콘 VMQ 3.53mm 코드·50A, 커스텀 둘레라 코드 절단+splice(실리콘은 일반 CA 안 붙음 → Loctite 770+406 또는 마찰만), o-ring-stocks.eu/미스미. (참고용 보존)

## 10. 돌출 0(상·하면 플러시) 마감 — 부품 가이드

> 사용자 질문: 인서트/스탠드오프가 다양하지 않은데, 어떤 부품이면 돌출 0가 되나.
> **전제 핵심**: stacked-레일 설계는 **간격을 아크릴 레일이 만든다 → 다양한 길이 스탠드오프 불필요**(기존 "부품 다양성" 문제 자체가 소멸). 남는 건 볼트 **양 끝 종단 마감**뿐.

### A. 섹스볼트(바인딩포스트/시카고스크류) — 양면 플러시·단일 부품 ★권장

- 암(barrel) + 수(screw)가 스택 **가운데서 만남** → 양쪽 헤드가 외면에 안착, **양면 동시 마감**. (출처: 양면 flush가 섹스볼트의 정의)
- 측당 6홀: barrel(아래서) + screw(위에서). barrel 길이 ≈ 스택−스크류물림 (21.6mm → barrel ~~16~~18 + M3 screw).
- 저프로파일/트러스 헤드 = 거의 플러시. **가벼운 카운터싱크 챔퍼**면 완전 플러시 = 돌출 0.
- 장점: 단일 부품이 전 스택 관통(스탠드오프 다양성 불필요), 양면 클린, 분해 가능. M3 메트릭 섹스볼트(저프로파일 소켓 포함) 시판.

### B. 블라인드 열간 인서트(보유 M3) + 하단 스크류 — 윗면 무홀·보유부품 활용

- 베젤 **밑면에서 블라인드 인서트 압입**(두께 안에서 멈춤 → 윗면 솔리드·홀 없음). **윗면 완전 클린**.
- 긴 M3 스크류를 **하판 밑**에서 위로 → 스택 클리어런스홀 관통 → 베젤 인서트에 체결. 헤드는 고무발에 은닉.
- 보유 M3 열간 인서트 활용. 추가 구매 = 긴 M3 스크류(~20mm)뿐.
- ⚠️ 베젤 3mm는 인서트 물림 얕음(~~2.5mm). 견고히 하려면 **베젤 4~~5mm**(여전히 1자판) 권장. 블라인드홀 = 인서트보다 ~1mm 깊게, 아래 ~0.75mm 여유.

### C. 접시(카운터싱크) M3 + F-F 바렐/표준오프 — 양면 플러시

- 상·하 홀을 90° 챔퍼 → 접시머리 M3가 묻힘. 중앙 F-F 바렐에 양끝 체결. 카운터싱크 비트로 아크릴 챔퍼(연질이라 쉬움).

### 권장 요약

- **A 섹스볼트** = 양면 완전 플러시 + 단일 부품 → "부품 다양성" 문제 정면 해결(새로 구매하되 가장 깔끔).
- **B 블라인드 인서트** = 보유 M3 인서트로 윗면 무홀 클린 + 하단 발 은닉(추가 구매 최소).
- 공통: 아크릴은 저속 드릴·디버링으로 크랙 방지. 레이저 도면은 클리어런스 홀만, 챔퍼/블라인드 깊이는 후가공.

## 11. 벽 0 · 스크류 0 · 인서트 0 — 스크류리스 결착 (리서치 결론)

> 사용자 질문: 좌우 벽도, 스크류·인서트도 다 빼면 최적은?
> **재발견(가장 중요)**: 핫스왑이라도 **풀 보강판의 스위치 클립이 plate를 PCB 위 3.5mm에 띄워 고정**한다(스위치 몸통이 갭을 span). → **갭 유지용 스페이서/벽은 원래 불필요.** 남는 과제는 ① plate 들림 방지 ② plate+PCB 덩어리 가두기뿐.

### 부품 0짜리 핵심 트릭 (둘 다 추가 부품·돌출 없음)

1. **갭 = 스위치가 만든다** — 풀 보강판 필수(하프 플레이트는 핫스왑 금지: 무지지 스위치가 소켓 손상).
2. **plate 들림 방지 = 베젤 개구부 턱** — 베젤 개구부 < 보강판 외곽 → 보강판이 베젤 아래에 갇혀 위로 못 빠짐. 부품 0.

### 덩어리 가두기 + 케이스 닫기 (벽·나사·인서트 0 후보)

| 방법                                 | 가역성(PCB 교체) | 돌출 | 벽0 부합           | 비고                                                                                     |
| ------------------------------------ | ---------------- | ---- | ------------------ | ---------------------------------------------------------------------------------------- |
| **O-ring 가스켓 (Bakeneko)** ★검증됨 | ✅ 우수          | 0    | △ 작은 nub/턱 필요 | 핫스왑+스크류리스 **유일 양산 검증**. 클립인 스태빌 강제, 스위치 뽑을 때 plate 살짝 들림 |
| **솔벤트 용접 (cast 아크릴)**        | ❌ 영구          | 0    | ✅ 완전            | 부품·구조물 0, 최강·최투명. PCB 교체 불가. extruded는 크레이징→cast 필수                 |
| **매립 자석(+정렬핀)**               | ✅ 좋음          | 0    | ✅ 좋음            | 벽0에 가장 부합. 단 스택 가로지르면 자력 급감→홀딩력 실측·정렬핀 필요                    |
| 스냅핏/탭·에폭시                     | —                | —    | ✗                  | 아크릴 취성·돌출·외관으로 부적합(제외)                                                   |

### 최적 권고

- **가역성(PCB 교체) 원함 → O-ring 가스켓 마운트.** 검증된 유일 해법. 좌우 벽 대신 하판에 **낮은 점-기둥(nub) 몇 개**만(벽 아님) 세워 O-ring을 마찰로 건다. 베젤 턱이 plate 들림을 잡음. 분해는 덩어리째 들어올림.
- **영구 OK(PCB 교체 포기) → cast 아크릴 솔벤트 용접.** 진짜로 부품·구조물 0, 가장 견고·깔끔. 스위치 핫스왑은 위에서 가능, PCB만 봉인.
- 공통 필수: **풀 보강판**, **클립인 스태빌라이저**, O-ring/용접 시 **cast 아크릴**.
- ⚠️ 분리형 반쪽이 작아(133/152×95) O-ring 마찰 면적이 작음 → nub 수·O-ring 경도 실측 검증 필요.
