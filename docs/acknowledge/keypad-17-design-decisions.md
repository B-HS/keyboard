# keypad-17 — 설계 결정 (2026-07-12, 사용자 확정)

## 프로젝트 전제

- **새 17키 넘패드, PCB 미사용(3D print + handwire).** 케이스 기본 구조는 split-65 FDM 방식(top bezel+기둥 / plate / bottom, M1 하단 체결)에서 PCB만 제거한 형태로 승계.
- 레이아웃 SSOT = 사용자 제공 `keypad-17/raw/`: `plate.jscad`(컷 좌표) + `keyboard.kicad_pcb`(keebforge, 5×4 매트릭스 ROW0–4/COL0–3 + 1N4148×17). 두 파일은 동일 좌표계이며 `config/layout.ts`가 y-up으로 변환해 보유(23컷 전수 수치 대조 완료).
- 스택: 기존 그대로(Bun·Vite·JSCAD·three.js·React 19+Compiler).

## 결정 사항

1. **컨트롤러 = ESP32-C3 SuperMini** — 핸드와이어 9핀(ROW5+COL4). 하판 크래들(65와 동일 레일 구조, 보드 18.0×22.52) 뒷변 배치, USB 뒷쪽 노출.
2. **plate 고정 = 기둥 + plate 홀 추가** — 기둥 6개(코너4+좌우중앙2)가 plate 홀을 관통, **하판 보스(OD Ø7.4)가 기둥을 감싸고 올라와 boss 상면이 plate 하면을 받침** → M1 체결 시 베젤 밑면과 보스 상면 사이에 plate가 클램프. PCB 캡·shoulder 없음(조립 경로 단순).
    - **정정 (2026-07-12, 홀 Ø6.4 → Ø5.4 + 카운터싱크)**: Ø6.4 는 split-65 의 "캡(Ø5.8) 통과" 조건에서 온 수치인데 keypad-17 은 캡이 없어 근거 없이 컸고, 기둥 몸통(Ø4.8) 대비 **측면 유격 ±0.3(M1 마찰에만 의존)** — 사용자 지적(plate 흔들림). 관통홀 **Ø5.4**(몸통 +0.3/측 슬라이드, 65 FDM 수축 교훈 반영) + **상단 1.0mm 카운터싱크 Ø5.4→6.0**(뿌리 필렛 Ø4.8→5.8 과 동일 구간, +0.1/측)으로 교체 → 유격 **±0.1** + 조임 시 테이퍼 자가 센터링, 6기둥 동시 슬라이드 조립성 유지. smoke 에 핏 가드 2종(슬라이드·카운터싱크) 추가.
3. **바텀갭 = 7.0mm** — 사용자 선택은 6mm였으나, 6mm에서는 **크래들 레일 상단(-8.2)과 스위치 핀 끝(-8.3, 하우징 -5.0 − 핀 3.3)이 0.1mm 간섭**함을 설계 중 발견. 근본 해결로 7.0mm 채택(핀↔레일 여유 0.9, 배선 여유 3.7). 전고 +1mm(총 18.5). `BOTTOM_GAP` 상수 하나로 조정 가능.
    - **정정 (2026-07-12, 바텀갭 9.0 재확정)**: 위 7.0 결정은 레일↔핀만 검증하고 **레일 안의 모듈 본체·핸드와이어 솔더 여유를 누락** — 뷰어에서 모듈↔row0 스위치 겹침 발견(사용자). 크래들은 어느 변에 두어도 보드 깊이 22.82 ≫ margin 6 이라 스위치 밑을 벗어날 수 없어 Z 로만 해결 가능. `BOTTOM_GAP` 을 파생식 `핀 3.3 + 솔더 1.2 + 모듈최악고 3.4(쉴드캔 변종) + 마진 1.1 = 9.0` 으로 교체(마진 0.6 → 사용자 요청으로 1.1 상향), 전고 20.5. smoke 가 간섭 3종(본체·레일·USB-y)을 자동 검증. 상세: `docs/bug/2026-07-12-esp32-switch-pin-overlap.md`

## 주요 파생 치수

- 케이스 외곽 88.2×107.25 (raw plate 82.2×101.25 에서 **여백 3→6mm 확장** — 기둥·보스 수용. raw plate 원본 그대로는 홀 배치 공간 부족)
- 기둥 Ø4.8 + 뿌리 필렛 Ø5.8(65 3차 교훈) + 팁 챔퍼 Ø3.8 / 보스 보어 Ø5.5 슬립핏 + 입구 챔퍼(발거 파단 대책 승계)
- 마운트홀 중심 = 그리드 가장자리 밖 **2.0mm** (`MOUNT_HOLE_OUTSET`, 2026-07-12 전수검사에서 1.5→2.0 — 중앙 보스↔하우징 갭 0.33→0.83, plate 컷웹 ≥1.5)
- M1 나사머리 카운터보어 Ø2.8×0.9(하판 밑면, 머리 은닉) + 인서트 포켓 3.6(나사끝 여유 0.4, M1×4 유지, 풀 물림 2.5) — 전수검사 반영, 상세 `docs/quality-assurance/keypad-17-assembly-audit.md`
- 스택: bezel 5.0 / plate 1.5 / 하우징 3.5 / 배선 **9.0** / 바닥 1.5 = 총 **20.5mm** (2026-07-12 바텀갭 정정 반영)
