# 기둥 발거 파단 (분리 시 기둥째 뜯김) — 보어 슬립핏 + 챔퍼 + 뿌리 필렛

## 증상

- 실척 출력물(top+bottom) 결합은 정상("결착 잘 됨"). **분리 시 기둥 1개가 기둥째 뜯겨 top에서 이탈.**
- 사용자 실조립(2026-07-10)에서 발견.

## 원인

세 요인의 결합. 근본 원인은 1(마찰 과다)이고 2·3은 파단 위치·양상을 결정.

1. **보스 보어가 사실상 억지끼움**: 보어 Ø5.0 vs 기둥 Ø4.8 = 편측 0.1mm. FDM 구멍은 0.1~0.25mm 작게 출력되므로 실물은 간섭 끼움. 설계상 유지력·정렬은 M1 나사(클리어런스 Ø1.2, 편측 0.1)가 담당하므로 보스가 마찰로 잡을 필요가 없는데 잡고 있었음. 발거 시 이 마찰력 전부가 기둥 축방향 인장으로 전달.
2. **적층 방향이 축방향 인장에 최약**: top은 뒤집어 출력(베젤 베드 밀착) → 기둥이 수직 타워로 적층되어 레이어가 축과 직교. 축방향 인장 = 레이어 간 접착 강도(벌크의 절반 수준)로만 버팀 → "부러짐"이 아니라 레이어에서 "뜯김".
3. **뿌리 응력 집중**: 기둥(Ø4.8)이 베젤 밑면에 직각·무필렛으로 접합. 비스듬히 젖히는 분해 동작의 굽힘이 이 직각 코너에 집중.

## 해결 (2026-07-10, 사용자 확정 — 가능한 대책 전부 적용)

| 항목                  | 변경                                                        | 상수                         |

| 보스 보어             | Ø5.0 → **Ø5.5** (편측 0.35, 슬립핏 — 발거 저항 자체를 제거) | `BOTTOM_BOSS_BORE_DIAMETER`  |
| 보스 OD               | Ø6.6 → **Ø7.1** (보어 확대분 벽두께 0.8 유지)               | `BOTTOM_BOSS_OUTER_DIAMETER` |

- 뿌리 필렛 최대 지름을 **캡과 동일한 Ø5.8**로 제한 — plate 홀 Ø6.4의 통과 조건이 기존 캡 통과와 동일해서 조립 경로 불변.
- 구현: `65/parts/case-fdm.ts` — `cone` 헬퍼(`cylinderElliptic`) 추가. 필렛 콘은 기존 패턴대로 overshoot 후 `belowTiltPlane(Z.plateTop)` 클립(경사 어깨는 clip 지점에서 정확히 Ø5.8).
- 출력 배향 정합: 필렛 콘은 베드 쪽으로 넓어지는 버트레스(무서포트), 팁 챔퍼·포켓 입구 챔퍼는 출력 최상단에서 좁아지는 방향(무서포트), 보어 입구 챔퍼는 정방향 bottom의 윗면 카운터싱크(무서포트).

## 호환성

- **PCB(발주분, 홀 Ø5.4) 무변경 호환** — PCB 접점(몸통 Ø4.8·캡 Ø5.8)은 미변경. 캡 위 필렛 구간(z4.0~5.0)에는 PCB가 도달하지 않음(캡 z0.8 정지).
- **plate(기출력분) 재사용 가능** — plate 형상 미변경, 필렛 Ø5.8 ≤ 기존 캡 통과 조건.
- **재출력 필요: top·bottom 2종만.**

## 교훈

- **끼워맞춤 공차는 "무엇이 유지력을 담당하는가"부터 정한다.** 나사가 있으면 가이드 구멍은 슬립핏이 정답 — 마찰 유지력은 공짜가 아니라 분해 시 최약 부재(FDM 수직 타워의 레이어 접착)가 지불한다.
- FDM 구멍은 도면보다 작게 나온다(0.1~0.25mm). 편측 0.1 공차는 FDM에서 억지끼움 선언과 같다.
- 수직 기둥 뿌리는 항상 필렛/콘으로 받친다 — 조립 경로가 허용하는 최대 지름까지.
