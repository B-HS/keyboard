## 후기
- 49키는 쓰기 매우 힘들다
- 제발 유격좀 넣고 나사로 고정할 생각을하자
- 납땜은 진짜 꿀잼이니 다른것도 만들어보자
- JSCAD말고 진짜로 Modeling을 해보자
- PCB짜는것도 자신감 붙었으니 나중에 부품을 공부해서 더 달아서 써보자
- 얇은건 CNC로 깎자. 3D로 뽑으면 수치 박살나서 매우 힘들다
