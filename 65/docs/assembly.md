# 65 FDM 케이스 — 조립 가이드

> 개정 3차(보어 슬립핏·챔퍼·뿌리 필렛, `docs/bug/2026-07-10-pillar-torn-on-extraction.md`) 기준의 정식 조립·분해 절차다.
> 설계 상세는 [fdm-m1-case.md](./fdm-m1-case.md), 치수 정본은 `65/config/dimensions.ts`.

## 1. 준비물

| 품목                            | 수량(측당)       | 좌우 합계 | 비고                                                                                           |
| ------------------------------- | ---------------- | --------- | ---------------------------------------------------------------------------------------------- |
| top (bezel+기둥 6, 출력물)      | 1                | 2         | **개정 3차 반영본 재출력 필수** (팁 챔퍼·뿌리 필렛·포켓 입구 챔퍼)                             |
| plate (출력물)                  | 1                | 2         | 기존 출력분 재사용 가능 (형상 무변경)                                                          |
| bottom (평판+보스 6, 출력물)    | 1                | 2         | **개정 3차 반영본 재출력 필수** (보어 Ø5.5·OD Ø7.1·입구 챔퍼)                                  |
| PCB                             | 1                | 2         | 발주분(마운트홀 Ø5.4) 무변경 호환                                                              |
| 스위치                          | 좌 30 / 우 35    | 65        | 핫스왑                                                                                         |
| M1 히트 인서트 (OD 2.0 × L 2.5) | 6                | 12        | 기둥 끝 포켓 Ø1.75                                                                             |
| M1×4 나사 (헤드 제외 길이 4mm)  | 6                | 12        | 팬헤드/체즈헤드 (헤드 Ø≈2.0). **5mm 이상 사용 불가**(포켓 3.0 바닥침), 3mm는 물림 1.5로 비상용 |
| 스태빌라이저 (plate-mount)      | 스태빌 키 수만큼 | -         | plate 스태빌 컷(6.8×14.8)에 장착                                                               |
| 컨트롤러 보드 (ESP32)           | 1                | 2         | bottom 크래들 슬롯 18.0×22.52                                                                  |

공구: 인두(인서트 열압입), M1 드라이버.

## 2. 출력 (top·bottom 재출력)

- export: `bun run export:65-fdm` → `65/export-out/fdm/` 또는 웹패널 STL Export. 배향은 export에 이미 반영(top=뒤집힘, bottom=보스 위, 전부 서포트 0).
- 슬라이서: 벽(perimeter) **4–5**(Ø4.8 기둥 통벽화), 노즐 온도 **+5–10°C**(레이어 접착), XY hole compensation OFF, 레이어 0.15. 소재 PLA 가능, PETG면 레이어 접착 우위.
- 마감(사용자 확정): 베젤 상면 물사포 400→800→1000, 윗면 ironing.

## 3. 인서트 열압입 (top 준비)

1. top을 뒤집어(기둥 위) 고정한다.
2. M1 인서트를 기둥 끝 포켓(Ø1.75, 입구 챔퍼 Ø2.2)에 얹고 인두로 **수직으로** 가열 압입한다.
3. **기둥 끝면과 면일치(flush)까지만** 넣는다. 과압입 금지 — 나사 물림 깊이(2.5)가 얕아진다.
4. 측당 6곳 × 좌우 = 12곳.

## 4. 샌드위치 선조립 (plate + 스위치 + PCB)

1. 스태빌 키가 있으면 스태빌라이저를 plate에 먼저 장착한다.
2. 스위치를 plate 컷(14.0)에 클립한다.
3. PCB를 스위치 핀에 정렬해 핫스왑 소켓에 끝까지 삽입한다 — plate·스위치·PCB가 한 덩어리(샌드위치)가 된다.

## 5. 케이스 결합

1. top을 뒤집어(기둥 위) 놓는다.
2. 샌드위치를 기둥 6개에 맞춰 내린다 — **plate 홀 Ø6.4는 기둥 전체(캡 Ø5.8·뿌리 필렛 Ø5.8 포함)를 통과**하고, **PCB 홀 Ø5.4는 캡 어깨에 걸려 정지**한다. plate가 베젤 밑면까지 내려가 스위치 스택으로 클램프되면 정상.
3. ESP32 보드를 bottom 크래들에 뒤쪽 열린 방향에서 레일 립 아래로 밀어 넣는다(앞 stop wall에 닿을 때까지).
4. bottom을 기둥 끝에 맞춰 덮는다 — 팁 챔퍼(Ø3.8)와 보어 입구 챔퍼(Ø6.1)가 리드인이라 정렬만 맞으면 **힘 없이 슬립핏**으로 들어간다. 억지로 눌러야 하면 정렬이 틀어진 것이니 다시.
5. M1×4 나사를 하판 바깥에서 6곳 체결한다. **살살 — M1은 과체결에 매우 약하다.** 헤드가 하판 면에 닿으면 끝(카운터보어 없음, 헤드 0.8 돌출은 정상).
6. 뒤집어서 키캡을 씌운다.

## 6. 분해

1. 키캡은 그대로 둬도 된다. **나사 6곳(측당)을 전부 푼다.**
2. top·bottom을 **곧게 수직으로** 분리한다. 슬립핏이라 손힘으로 빠진다.
3. **한쪽을 지렛대처럼 젖히지 않는다** — 굽힘이 기둥 뿌리에 집중된다(구 설계 파단 원인의 하나).

## 7. 첫 조립 시 확인 (QA)

- [ ] 나사 없이 top+bottom 결합 → 손힘만으로 부드럽게 삽입·발거되는지 (저항 크면 보어 공차 재캘리브레이션)
- [ ] PCB 하면 보스 접촉 링(Ø5.5–7.1) 6곳에 부품·트레이스 간섭 없는지 육안 확인
