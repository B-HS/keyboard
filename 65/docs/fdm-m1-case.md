# 65 케이스 — FDM(A1 mini) + M1 기둥 체결 변형 설계

> **개정 4차(2026-07-12): 바텀갭 3.5→5.7 — 틸트 삭제로 무효화된 ESP32 크래들 정합.** 크래들(2026-07-07)은 틸트로 후방 갭 ~15mm 전제였는데 개정 2차의 틸트 삭제로 갭이 균일 3.5 가 되며 모듈(USB 포함 4.2)이 **PCB 를 0.7 관통·삽입 불가**, 본체(쉴드 worst 3.4)는 핫스왑 소켓 바닥(−3.6)과 간섭. `BOTTOM_GAP` 을 파생식 `소켓 2.0 + 마진 0.3 + PCB 1.0 + 본체 2.4 = 5.7` 로 교체(`ESP32_MODULE`·`HOTSWAP_SOCKET_BELOW_PCB` 신설), smoke 간섭 가드 3종(본체↔소켓 0.3 / USB↔PCB 1.5 / 레일↔PCB 2.9). 스택 16.6→**18.8**, STL top 17.3/plate 1.5/bottom 7.2. PCB·plate 무변경 호환, **재출력 top·bottom 만**. 상세 `docs/bug/2026-07-12-esp32-cradle-tilt-removal.md`. 아래 2·3차 블록의 STL 실측치는 이력.

> **개정 3차(2026-07-10): 기둥 발거 파단 대책 — 보어 슬립핏 + 챔퍼 + 뿌리 필렛.** 실척 출력물 분리 시 기둥 1개가 기둥째 뜯김(`docs/bug/2026-07-10-pillar-torn-on-extraction.md`). 원인 = 보어 Ø5.0 vs 기둥 Ø4.8(편측 0.1)이 FDM 구멍 수축으로 억지끼움 → 발거 마찰이 레이어 간 인장강도 초과. 유지력·정렬은 M1 나사 담당이므로 보스는 슬립핏 가이드로 전환. 현행:
>
> - **보스 보어 Ø5.0 → Ø5.5**(편측 0.35 슬립핏) · **보스 OD Ø6.6 → Ø7.1**(벽 0.8 유지) · **보어 입구 챔퍼** 0.3/Ø6.1.
> - **기둥 팁 챔퍼** 0.5/Ø3.8 · **뿌리 필렛 콘** 1.0/Ø4.8→Ø5.8(캡과 동일 = plate Ø6.4 통과 조건 불변, 뿌리 단면 1.46배) · **인서트 포켓 입구 챔퍼** 0.3/Ø2.2.
> - 전부 무서포트 배향 정합(필렛=베드 쪽 버트레스, 팁·포켓 챔퍼=상단 수렴, 보어 챔퍼=윗면 카운터싱크). 초판 "미결·주의"의 shoulder 챔퍼(z0.8 단차)는 **캡 상면이 PCB 정지면이라 챔퍼 불가** — 폭 0.5 브리지 유지.
> - **PCB(발주분 Ø5.4)·plate(기출력분 Ø6.4) 무변경 호환. 재출력은 top·bottom 2종만.** STL 외형 불변(top 15.1/plate 1.5/bottom 5.0).
> - keepout 주의: 보스 접촉 링이 Ø5.5–7.1로 확장(기존 Ø5.0–6.6) — 마운트홀 6곳 하부 PCB 부품·트레이스 부재 확인 필요(기존 항목 승계).

> **개정 2차(2026-07-10): 틸트 삭제 + plate 조립 불가 결함 수정.** 아래 2026-07-07 틸트 블록은 **이력**이다. 현행:
>
> - **7.5° 틸트 삭제** — `TILT_DEG = 0`. 틸트 유틸(tiltGeom/tiltRise/tiltY/경사면 컷)은 파라메트릭으로 유지하되 항등. 스택 평평, 총 16.6mm(topFrameTop 10 ~ bottomBottom −6.6).
> - **plate 조립 경로 결함 수정** — 구 설계(홀 Ø3.4, 넥 안착)는 기둥 몸통 Ø4.8·캡 Ø5.8을 통과할 수 없어 **설치 자체가 불가능**했다(`docs/bug/2026-07-10-plate-captive-assembly.md`). 홀 **Ø6.4**(`PLATE_PILLAR_CLEARANCE_DIAMETER`)로 확대, plate는 **스위치 클립으로 PCB와 샌드위치**가 되어 고정(트레이마운트 방식): 위=베젤 밑면(plateTop 5.0) 클램프, 아래=스위치→PCB→보스, 옆=스위치가 plate 컷·PCB 홀 동시 결합.
> - **기둥 넥 제거** — 안착 렛지 소멸로 캡 위부터 베젤까지 **몸통 Ø4.8 일정**. 캡 Ø5.8(PCB 정지면·클램프)은 유지. 발주 PCB(홀 Ø5.4) 무변경 호환.
> - **조립 순서**: plate+스위치+PCB 샌드위치 선조립 → 뒤집은 top 기둥에 삽입(plate 전부 통과, PCB는 캡에 정지) → bottom(보스 보어 Ø5.0) → 하단 M1.
> - **STL 실측(2차 개정 후)**: top 15.1 / plate 1.5 / bottom 5.0mm. 웹 export(`stl-parts.ts`)에 **plate 추가**(측당 4장: top/plate/bottom/mock-pcb, 좌우 8장 — 이전엔 plate 누락 6장).
>
> ⚠️ **개정(2026-07-07): 7.5° 타이핑 틸트 통합.** 아래 "구조" 절의 절대 Z값은 초판(BOTTOM_GAP 5.0·무틸트) 기준이라 **stale** — 현행은 `BOTTOM_GAP 3.5`(bottomTop −5.1, bottomBottom −6.6) + 틸트로 기둥·보스 높이가 y별 가변. 현행 정본은 이 블록과 `docs/PROCESS.md` §4.2, 코드 `case-fdm.js`.
>
> - **틸트(A안)**: 하판 base 평평 유지, **기둥·보스는 수직 + 길이만 가변**(피벗=스페이스바 행 y −76.2, 뒤로 갈수록 `tiltRise(y)=(y−pivot)·sin7.5°` 만큼 김). PCB·plate·베젤은 `tiltGeom`으로 7.5° 기울여 baked. 바텀갭: 앞행 3.5 → 맨위열 ~13.5 → 케이스 뒷변 ~17.4.
> - **기하 정합**: 기둥·보스·인서트포켓·나사홀 XY는 `tiltY(y)=pivot+(y−pivot)·cos7.5°`(기운 PCB 홀의 투영 위치). 받침면(보스 top·칼라 밑/top·넥 끝)은 `above/belowTiltPlane`으로 **7.5° 경사면 컷** → PCB·plate와 면접촉. 이 보정 없이는 기둥이 PCB를 관통(발견→수정 완료).
> - **관통홀 확대**: 기운 판 ↔ 수직 핀이라 PCB 마운트홀 Ø5.0→**Ø5.4**, plate 넥 클리어런스 Ø3.2→**Ø3.4** (필요폭 4.8/cos7.5+1.6·tan7.5≈5.05).
> - **PCB 외곽 = `fdmOutline`**(caseOutline+1.5/변): 좌 **146.35×108.25** / 우 **165.40×108.25**, 홀↔가장자리 4.0(칼라 r2.9·보스 r3.3 내포). 홀 좌표는 `SIDES[k].mountHoles` **원본**(보드 로컬 — tiltY는 조립 공간용).
> - **STL 실측(개정 후, 2026-07-10 top untilt 반영)**: top 26.8 / plate 1.5 / bottom 17.0mm 높이(좌·우 동일 footprint, A1 mini 베드 내).
> - **미결(틸트분)**: ~~plate STL 틸트 export~~(해결 — `untiltGeom`으로 평판 1.5mm 복원) · ~~top 배향~~(**해결 2026-07-10, `ebfd2b5`** — CLI·웹 export 양쪽 top도 `untiltGeom` 적용(untilt→flip 순): 베젤 면 전체 베드 밀착(접촉 146.3×0.8→146.4×108.2), 기둥 7.5° 기운 타워, 무서포트. 뷰어는 틸트 유지. `docs/bug/2026-07-10-top-stl-tilt-export.md`), 아래 초판 "미결·주의"의 챔퍼·keepout·fit-coupon은 계속 유효.
> - **검증 출력 계획(2026-07-07 확정)**: A1 mini **1/5(SCALE=0.2)** 선출력으로 끼움·조립 검증 — `bun run export:65-fdm-mini`(0.2로 변경) 또는 **웹패널 STL Export**(scale 지정, top/bottom/**mock-pcb** 좌우 6장 개별 다운로드, `65/export/stl-parts.ts`). mock-pcb = fdmOutline + Ø5.4 홀 6, 두께 1.6×scale. 1/5에서 검증 가능: 기둥(Ø0.96)→보스 삽입·plate 안착·틸트 비율 / 불가: M1 포켓(Ø0.35)·실스위치 끼움(컷 2.8), mock-pcb 0.32mm(1~2레이어) 휨 주의.
> - **마감 결정(2026-07-07, 사용자)**: **서포트 0 유지**(자국이 텍스처보다 나쁨). textured PEI 무늬 전사 — top 뒤집기 배향이라 **베젤 상면=베드면**에 무늬가 새겨짐 — 는 스무스 플레이트 구매 없이 **사포 후처리(400→800→1000 물사포)**로 해결 확정. 윗면 ironing, 측면 레이어 0.12~0.15 + seam aligned. 베드 굴곡 자체는 A1 오토레벨링이 보정(문제 아님).

## 맥락

65는 원래 cast 아크릴 CNC/레이저컷 전제(DXF-only). 사용자가 `esp32-keypad`(pad-11)를 A1 mini로 실제 출력·조립 성공한 뒤, 65를 같은 A1 mini에 **M1 하드웨어 + 벽 없는 기둥 구조**로 재설계 요청. **아크릴 DXF 경로(`export.js`)는 그대로 유지**하고 FDM STL 경로(`export-fdm.js`)를 병행. 부품은 나사·인서트(M1 키트)를 제외하고 **전부 3D 프린트**.

## 설계 판정 (Workflow 3관점 + judge 도출)

- **plate+bezel 합침 불가**: 합치면 어떤 배향이든 plate가 키캡 opening을 브리지 → 서포트 필요. 분리가 유일한 무서포트 방법. (당시 결론이던 "drop-in 안착"은 이후 조립 경로 결함으로 판명 — 현행은 스위치 샌드위치 방식, 상단 개정 2차 블록·`docs/bug/2026-07-10-plate-captive-assembly.md` 참조)
- **M1×4(최대 4mm) 통짜 관통 불가**: 스택 gap(5·1.6·3.5)을 못 뚫음. → 나사가 얇은 층 하나만 관통(≤1.5) + 인서트 물림(2.5) = 4.0. **하단 열린 면에서만 진입**, 상판 상면 구멍 0.

## 구조 (측당 3 파츠 전부 프린트)

### TOP — bezel + 6 관통기둥 (일체 1파츠)

- bezel: `buildTopFrame2D(side, fdmOutline)` extrude Z[5..10]
- 기둥 ×6 at `computeMountHoles` (코너4 + 좌우중앙2), 적층 원통(절대 Z):
    - Z[−6.6..0] Ø4.8 몸통 (하부 gap + PCB Ø5.0 구멍 관통). 바닥 z=−6.6에 M1 인서트 포켓 Ø1.75×3.0 (아래로 열림)
    - Z[0..0.8] Ø5.8 칼라 = PCB 상면 캡 (>Ø5, PCB 위 랩)
    - Z[0.8..3.5] Ø4.8 상부 스탠드오프, 상면 z=3.5 = plate 안착 ledge
    - Z[3.5..5] Ø3.0 넥, plate 관통, bezel 하면 z=5 병합

### PLATE — 분리 drop-in (1파츠)

- 평판 Z[3.5..5], outline `fdmOutline`, 컷 = 스위치 14.0 + 스태빌 + 넥 클리어런스 홀 Ø3.2 ×6. 나사·보스 없음. 기둥 shoulder(z3.5)와 bezel 하면(z5) 사이에 **무나사로 갇힘**

### BOTTOM — 평판 + 6 PCB 지지 보스 (1파츠)

- base: `rect(fdmOutline)` extrude Z[−8.1..−6.6]
- 보스 ×6: OD Ø6.6, 보어 Ø5.0(기둥 Ø4.8 받음), Z[−6.6..−1.6]. 보스 상단 z=−1.6이 PCB 하면 지지
- 나사 관통 Ø1.2 (base 관통, Z[−8.1..−6.6])

### PCB (외부, Ø5.0 마운트홀)

- 마운트홀 6곳 Ø2.4→**Ø5.0** (기둥 Ø4.8 관통). PCB는 보스(z−1.6)와 칼라(z0) 사이에 **무나사로 갇힘**. (65 PCB 미제작 상태 — 새로 Ø5.0으로 생성)

## 체결

- **BOTTOM → TOP 기둥**: M1×4, base 1.5 관통(Ø1.2) → 기둥 바닥 인서트(z−6.6, 물림 2.5). **1.5+2.5=4.0 = M1×4 정확**. 6개 전부 열린 하단(z−8.1)에서 축방향. **상판 상면 구멍 0개.**
- plate·PCB는 나사 없이 고정 슬롯에 갇힘.

## 출력 배향·세팅

- 배향(`export-fdm.ts`): **TOP untilt 후 뒤집음**(export 시 `untiltGeom`으로 7.5° 제거 → bezel 상면이 베드에 평평히 밀착, 기둥은 7.5° 기운 타워, 인서트 포켓 위로 — 2026-07-10 `ebfd2b5`) / **BOTTOM 정방향**(보스 위) / **PLATE 정방향**(untilt 평판). 전부 서포트 0.
- 재료 PLA · 레이어 0.15mm · 엘리펀트풋 0.1~~0.15 · 브림 5~~8mm · 컷아웃 14.0 반영이므로 슬라이서 XY hole comp OFF
- **1/5 검증 모형(현행)**: `bun run export:65-fdm-mini`(SCALE=0.2) → `65/export-out/fdm-mini/` (29~33mm). 끼움·조립 검증용 — 상세는 상단 개정 블록. 웹패널 Export로도 동일 산출 가능

## 미결·주의 (실물 전)

- **기둥 shoulder 챔퍼 미적용**: TOP 뒤집기 출력 시 z0.8(Ø4.8→5.8)·z3.5(Ø3.0→4.8) 단차가 오버행. 폭 0.5~0.9mm라 브리지 가능하나, 처짐 심하면 45° 챔퍼 콘 추가 필요.
- **keepout 확인**: 보스 Ø6.6이 마운트홀 keepout Ø5 반경보다 0.8 초과. 마운트홀은 케이스 margin(스위치 bbox 밖 2.5)이라 대개 bare PCB이나, 6곳 하부에 부품·트레이스 없는지 확인.
- **mid-span 강성**: 벽 제거로 지지는 6기둥뿐. 대형 우측(165mm)에서 plate 중앙 처짐 시 중앙열에 무나사 rest post 추가 가능(같은 mountHole 맵에 XY 추가).
- **fit-coupon**: 스위치 1구 + 기둥 1개 쿠폰으로 14.0 끼움·M1 체결 실측 캘리브레이션 권장.
