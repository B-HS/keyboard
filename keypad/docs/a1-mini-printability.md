# keypad 케이스 — Bambu Lab A1 mini 출력 가능성 검증 (2026-07-03)

## 대상 파일

- `keypad/parts/*.js` · `keypad/config/dimensions.js` · `keypad/config/layout.js` · `keypad/export-out/*.dxf`

## 결론

**출력 가능하나, DXF 수치 그대로는 불가.** 5개 파츠 모두 크기·형상은 A1 mini(베드 180×180×180)에 여유 있게 들어가고 전부 평판 압출이라 서포트가 필요 없지만, 레이저컷 아크릴 전제로 튜닝된 XY 수치 2곳(스위치 컷아웃·엘리펀트풋)은 FDM 보정 없이는 스위치 물림에서 실패한다.

검증 방법: 코드 실측(bun으로 parts 모듈 직접 import → bounding box·최소 웹 계산) + DXF ENTITIES 교차검증 + 독립 재계산 검증 2회. 모든 수치 일치 확인.

## 파츠별 판정

베드 대비 여유: X 93.8 / Y 74.75mm. 최소 벽 1.3mm(M2홀↔외곽, 6곳 공통)은 0.8mm 최소 기준 이상 — 출력 가능, 과토크만 주의.

## 필수 보정 (안 하면 실패)

1. **스위치 컷아웃 13.75mm** — 레이저 커프(구멍이 커짐)를 전제한 값. FDM은 커프 0 + XY 구멍 수축 0.1~0.3mm → 실측 ~13.5mm가 되어 MX 하우징(14.0 표준)이 안 들어감.
    - 방법 A: 모델을 **14.1~14.2mm**로 키워 별도 출력본 생성
    - 방법 B: 13.75 유지 + Bambu Studio **XY Hole Compensation** (설정 +0.1 = 개구 +0.2mm이므로 +0.15~0.23 수준에서 실물 캘리브레이션)
2. **엘리펀트풋** — 첫 레이어 스퀴시는 내부 개구를 바닥에서 더 좁힘. 스위치면 **face-down 배향** + 슬라이서 엘리펀트풋 보정 병행.

## 권장 세팅

- **재료**: plate는 PLA(치수 정확도 최우선). 나머지 PLA/PETG. 오픈 베드라 ABS/ASA/PC 회피.
- **레이어**: 0.2mm는 1.5mm와 비정합(7.5레이어). **0.15mm(×10)** 또는 0.25mm(×6).
- **M2 Ø2.4홀**: 관통 클리어런스 용도(현 설계: bottom→plate 관통볼트 + 너트/PCB 체결)로는 그대로 OK. 셀프태핑은 불가(파일럿 ~1.7 필요), 힛셋 인서트도 불가(~3.2 필요).
- spacer 막대·1.5mm 박판: 브림 + 첫레이어 접착 관리.

## 참고

- **split-65 레퍼런스 케이스는 A1 mini 불가**: top/bottom-case 282.35×91.85mm — 베드 180mm는 물론 대각선(~254mm)도 초과. 분할 없이는 절대 안 들어감. keypad를 소형 prototype으로 만든 판단이 유효함을 방증.
- 컷아웃 13.75 확정 이슈(PROCESS.md §3 "실물 끼움으로 확정")는 CNC 기준 — FDM 테스트 시에는 위 보정값 기준으로 별도 캘리브레이션 필요. 두 공정의 결과를 혼동하지 말 것.
- A1 mini 스펙 출처: bambulab.com/en/a1-mini/tech-specs, wiki.bambulab.com (빌드볼륨 180³, 기본 노즐 0.4mm, 권장재 PLA/PETG/TPU).
