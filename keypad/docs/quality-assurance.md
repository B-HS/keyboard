# keypad 검증 체크리스트 (prototype 발주 전/후)

> 저손실 prototype의 목적 = 발주 전 디지털 검증 + 실물로 끼움·결착·타건을 확인해 split-65 발주 리스크를 낮춘다.

## A. 발주 전 (디지털)

- [x] `bun run smoke:keypad` 통과 (17키, 케이스 86.20×105.25, 마운트홀 6)
- [x] `bun run export:keypad` DXF 5장 생성
- [x] `bun run build` 뷰어 번들 통과 / `bun run dev` 65+keypad 한 화면 동시 렌더
- [ ] **뷰어 육안 확인**(`bun run dev` → keypad): 스위치/키캡/세로 2u/회전 스태빌 위치, 베젤 개구부, 마운트홀 6, 스택 18.1mm
- [ ] DXF를 CAD(LibreCAD/Illustrator)에서 열어 외곽·홀·컷아웃 치수 실측
- [ ] PCB(`pcb-requirements.md`): Edge.Cuts·M2홀·(핫스왑/솔더)·컨트롤러 반영

## B. 발주 후 (실물)

- [ ] 아크릴 레이어 5종 CNC 수령 → 두께·외곽·홀 실측 (DXF 대비)
- [ ] 스위치가 보강판 컷아웃(13.75)에 스냅핏 — 너무 빡빡/헐거우면 컷아웃 보정값 기록 → 65에 반영
- [ ] 베젤+보강판 본딩(아크릴 접착제) 후 일체형 상판 평탄도
- [ ] M2 인서트 압입(아크릴 크랙 여부) + 하단진입 볼트 6본 체결 — 클램프 견고성
- [ ] 좌우 벽 스페이서가 PCB/플레이트 하중을 받는지, 앞뒤 처짐 정도
- [ ] PCB 장착·타건(스태빌 2u 흔들림, 키캡 간섭)
- [ ] 전체 스택 높이 실측 vs 18.1mm

## C. → split-65 반영(Phase 5)

- [ ] 컷아웃 끼움값(13.75 vs 13.95) 확정 → 65 `SWITCH_CUTOUT` 반영 여부
- [ ] M2 볼트 길이·인서트 압입 깊이 실측 → 65 BOM 확정
- [ ] 좌우 벽/클램프 강성 판단 → 65 스페이서 보강 필요 여부
- [ ] 검증 OK면 split-65 발주 진행
