# keypad BOM (구매 목록)

> 17키 넘패드 prototype. 65 BOM(`docs/acknowledge/bom-aliexpress.md`)의 축소판. 수량은 keypad 1대 기준.

## 케이스 결착 (65 v3와 동일 방식)

| 부품           | 규격                         | 수량 | 비고                                    |
| -------------- | ---------------------------- | :--: | --------------------------------------- |
| M2 볼트        | 버튼헤드 14~16mm, 스테인리스 |  6   | 하단 진입(마운트 6곳). 스택 18.1mm 기준 |
| M2 열간 인서트 | 황동 플랜지형 L3~4           |  6   | 일체형 상판에 압입                      |
| M2 평와셔      | M2                           |  6   | 하판 압력 분산                          |
| 고무발         | Ø8~~10 h3~~4                 | 4~6  | 하단 볼트머리 은닉                      |
| 아크릴 접착제  | 솔벤트(Weld-On 등)           |  1   | 베젤+보강판 본딩                        |

## 스위치/전장

| 부품         | 규격                  | 수량  | 비고                                    |
| ------------ | --------------------- | :---: | --------------------------------------- |
| MX 스위치    | Cherry MX 호환        |  17   |                                         |
| 다이오드     | 1N4148 SOD-123        |  17   | 매트릭스(PCB에 풋프린트 존재)           |
| 스태빌라이저 | MX 2u                 |   3   | 세로 2u ×2 + 가로 2u ×1                 |
| 핫스왑 소켓  | Kailh MX              | (17)  | **핫스왑 선택 시만**. 현재 PCB는 솔더식 |
| 키캡         | 1u ×14, 2u ×3         | 1세트 |                                         |
| 컨트롤러     | Pro Micro / RP2040 등 |   1   | 미결정(`PROCESS.md`)                    |

## 가공·발주 (별도)

- **CNC**(cast 아크릴): `bun run export:keypad` → `keypad/export-out/*.dxf` 5장(bezel5.0·plate1.5·bottom1.5·spacer-airgap3.5·spacer-bottomgap5.0).
- **PCB**: `keypad/docs/pcb-requirements.md` 기준으로 Edge.Cuts·마운트홀 추가 후 발주.
